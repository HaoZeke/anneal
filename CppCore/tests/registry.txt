# Every test meson and CMake register, with the features that enable it.
#
# Both build systems read this file: CppCore/meson.build, and
# cmake/RgpotTestRegistry.cmake for CppCore/tests/tests.cmake. They register
# the unit, fortran, nlist, py and rerun entries from it in a loop, and take
# every entry's options from it. A custom entry is built next to its fixtures
# in each build system, under the same gate. CMake registers no test unless
# RGPOT_BUILD_TESTS is on, whatever the gate. check_test_registry.py, run as
# the test_list_parity test, compares the tests a configured build registered
# with the entries its features enable, so a test missing here or in either
# build system fails it.
#
#   name | gate | kind [arguments] [options] | [@reason]
#
# gate: clauses separated by spaces, all of which must hold. A clause names
# one feature, or several separated by commas of which one must hold.
#
#   tests         with_tests / RGPOT_BUILD_TESTS
#   core          the potential library: not the RPC client-only build
#   client        the RPC client-only build
#   rpc           the Cap'n Proto stack (with_rpc, or client-only)
#   fortran       the Fortran potentials
#   cache         with_cache / RGPOT_WITH_CACHE (CMake forces it off in the
#                 client-only build)
#   ipi           the i-PI server and driver client
#   eam_table     tabulated EAM / Finnis-Sinclair
#   xtensor       the xtensor faces
#   cp2k          the CP2K frontend and shim
#   mpi           librgpot_mpi, built against an MPI found at configure
#   mpiexec       an MPI launcher (mpirun or mpiexec)
#   linux         the host is Linux
#   posix         the host is not Windows
#   python        a python3 interpreter
#   capnp         the capnp and capnpc libraries
#   capnp_tool    the capnp compiler
#   rustc         a Rust compiler
#   tsan          -fsanitize=thread compiles and no sanitizer is configured
#   isa_variants  at least one MinimumImage ISA variant builds
#   toplevel      the build is not a subproject
#   examples eigen water xtb tblite dftd3 dftd4 xckernel long_range expr
#   metatomic skala
#   rust_core     meson-only features (meson options of the same name)
#   probe         an optional program or module the build looks for: the
#                 test may be absent even when the rest of the gate holds
#
# kind:
#
#   unit EXE SOURCE     Catch2 test in CppCore/tests, linked to the library
#   fortran EXE SOURCE  program in CppCore/rgpot/fortran, linked to the kernels
#   nlist EXE SOURCE    example in CppCore/examples, linked to the neighbour
#                       archives
#   py SCRIPT [ARG...]  SCRIPT relative to the source root, where @root@ is
#                       the source root and @capnp@ the capnp compiler
#   rerun TEST          TEST's executable again, under these options
#   custom              built and registered by hand in each build system
#
# options:
#
#   timeout=SECONDS     default 30
#   suite=NAME
#   workdir=DIR         relative to the source root, . for the root itself.
#                       unit defaults to . and other tests run in a build
#                       directory unless they name one
#   env=NAME=VALUE      repeatable
#   serial              never runs beside another test
#   should_fail         passes when the command fails
#   fp_contract=off     unit only: the test source is compiled unfused, for
#                       oracles compared exactly with unfused sums
#
# @reason: the entry is meson-only. Each reason below says what CMake does
# not build.

@engines CMake does not build engines/: the drivers, engine plugins and the LAMMPS, PLUMED, GROMACS, OpenMM and i-PI harnesses these tests run.
@engine_plugins CMake does not build the rgpot_engine_* plugins (classical, MOPAC, NWChem) this test loads.
@examples CMake does not build the example executables.
@meson The test configures meson, reads meson's build directory, or reads a subproject only a meson wrap resolves.
@water CMake has no option for the water potentials.
@xtb CMake has no option for xtb.
@tblite CMake has no option for tblite.
@dftd CMake has no option for s-dftd3 or dftd4.
@xckernel CMake has no option for the XC kernel.
@long_range CMake has no option for the long-range electrostatics.
@expr CMake has no option for the Lepton expression potential.
@metatomic CMake has no option for libtorch, metatomic or UMA.
@skala CMake has no option for Skala.
@rust_core CMake does not build rgpot-core.

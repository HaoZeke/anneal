* Search surfaces

- =cluster_search(obj, grad, n, budget, seed=0, recommended=True, derived=False, *, ras=False)= :: \(3N\) point set. Always needs a gradient or force.
- =ensemble_optimize(obj, low, high, budget, ..., grad_fn=None)= :: design box. Gradient → hop and quench; no gradient → portfolio.
- =box_ensemble_optimize(...)= :: hop primitive. Requires =grad_fn=.
- =global_optimize(obj, low, high, budget, ...)= :: portfolio arms when the caller does not want hops.

See [[file:../howto/choose-driver.org][choose a driver]].

* Classical (values only)

- =Boltzmann(t_init, sigma)= :: Logarithmic cooling + Gaussian + Metropolis.
- =Fast(t_init, gamma)= :: Reciprocal cooling + Cauchy + Metropolis.
- =Gsa(t_init, q_v, q_a)= :: =Tsallis= cooling + =Tsallis= visit + =Tsallis= accept.

All called via =run(obj, low, high, preset, n_epochs, steps_per_epoch, seed, x0=None)=.
Each move is mirror-reflected into =[low, high]= and the neighbourhood is the
box, so =obj= is only evaluated inside it. =x0= starts the walk at a given
point; without it the start is a uniform draw. The start costs one
evaluation, so a run makes =1 + n_epochs * steps_per_epoch= calls.
=run_qmc= and =global_optimize= take =x0= as well.
=low=, =high= and =x0= may be any array-like of one shape, flattened in C order.
A coordinate with ~low == high~ stays fixed: =run=, =run_qmc= and
=global_optimize=, like =minimize=, make the calls of the same run on the
other coordinates, each point completed with the fixed values, and with
every coordinate fixed a run is one call, at =x0= or at =low=. A NaN
objective value counts as worse than every number, =+inf= included, so it
is never kept as the best.

* Walls

=Bounds(low, high, slack=1e-6)= takes an infinite wall but not a NaN one,
nor =low= above =high=: either is a =ValueError= naming the coordinate.
=anneal._core.Bounds=, the extension's own box, and the box a Rust caller
builds come from eindir-core's =Bounds::new=, which takes a NaN wall,
though no point lies in such a box: refusing it there belongs to
eindir-core. =PyObjective= refuses such a box, and every function that
takes a box or a handle refuses a NaN wall, =low= above =high=, and an
infinite wall it cannot work with, each a =ValueError= naming the
coordinate, before any call:

- =polish=, =shifted_qmc_polish=, =qmc_best1bin_scout= and
  =qmc_best1bin_scout_objective= take an infinite wall, though not an axis
  whose two walls are the same infinity, which holds no point;
- =qmc_polish=, =qmc_trust_region_poll=, =estimate_gle_omega0=,
  =gle_langevin=, =gle_langevin_preconditioned= and the other =*_objective=
  functions take finite walls however far apart;
- =additive_independence= and =low_discrepancy_points= take finite walls a
  finite width apart;
- =run=, =run_qmc=, =global_optimize= and the other drivers take finite
  walls whose widths stay finite when doubled and when added up, and
  =run_device= and =run_ensemble= finite walls.

* Advanced drivers

- =additive_independence(obj, low, high, max_fevals, seed=0, degree=8, ... n_pilot=0)= (values only, rank-1 surrogate).
- =gle_langevin(obj, grad, low, high, max_fevals, seed=0, omega0=0.2, dt=0.2, n_epochs=40)= (gradient, colored noise).

* Device and ensemble (same kernel)

- =run_device= (single chain, NumPy or CuPy bounds)
- =run_ensemble= (batched, =n_chains=, same kernel)

* Hamiltonian Monte Carlo (HMC) / quasi-Monte Carlo (QMC) variants (also exposed)

- =run_hmc=, =run_qmc= (see =python/anneal/__init__.py= and tests for current signatures).

All return dicts with =best_pos=, =best_val=, =n_evals= (or the rich =History= / =DeviceHistory= / =EnsembleHistory= objects from =run= / =run_device=).

* Search surfaces

- =cluster_search(obj, grad, n, budget, seed=0, recommended=True, derived=False, communicating=False, *, ras=False, start=None, length_scale=None, species=None, sigmas=None, rigid=False, layout="block", target=None, water_sites=None)= :: \(3N\) point set, or \(6N\) for =rigid=True= or =water_sites=.
  Always needs a gradient or force.
  =species= is one label per point and =sigmas= is one diameter per point; two or more labels add a swap move.
  A wide diameter ratio also tries one downhill unlike-pair exchange beside the microcanonical step and the inner-outer exchange.
  =layout= is =block= or =interleaved=.
  Once a recorded energy is at or below =target=, the hop stops.
  Because =species= and =rigid= keep the stock preset, either of them makes the search ignore =length_scale=.
  Above ten bodies, a rigid chart keeps the acceptance factor at 4.
  It also scales the orientation amplitude toward an acceptance ratio of one half.
  Ten bodies or fewer do neither.
  Rigid quenches use the same limited-memory Broyden-Fletcher-Goldfarb-Shanno (L-BFGS) descent.
  A rigid record accepts the root-mean-square force.
  The chain keeps the eight lowest distinct minima of its quenched start, accepted quenches and lowest recorded minimum.
  Each stall follows 1000 hops with no new lowest minimum.
  At each stall the walker moves to the lowest kept minimum that is neither its own nor one of the last four stall destinations.
  When no kept minimum qualifies, the walker stays put.
  Nothing is drawn, the run target is not read, and the lowest minimum is kept.
  =water_sites= gives the body-frame O, H, H positions of one rigid water.
  With it, =n= counts molecules, and the state is centres, then exponential-map rotations.
  The preset is then =Config.communicating_tip4p=, =Config.recommended_tip4p= or =Config.for_tip4p=.
  =water_sites= needs a start.
  It excludes =ras=, =derived=, =length_scale=, =rigid=, =species=, =sigmas=, and a non-block layout.
  A callback may raise a =BaseException= that is not an =Exception=, such as =KeyboardInterrupt=.
  The run then stops at the next evaluation, and the exception is re-raised.
- =ensemble_optimize(obj, low, high, budget, ..., grad_fn=None)= :: design box. Gradient → hop and quench; no gradient → portfolio.
- =box_ensemble_optimize(...)= :: hop primitive. Requires =grad_fn=.
- =global_optimize(obj, low, high, budget, ...)= :: portfolio arms when the caller does not want hops.

A callback that raises =BaseException= other than =Exception= (a harness
stop, or =KeyboardInterrupt=) ends the search at once. The best state
found is kept, and the exception is re-raised. The same stop closes a
Rust =Ledger= built with =with_stop=, including every budget slice, and
it closes a stock binary Lennard-Jones search and a rigid TIP4P search.
A flag that stays down does not change the number of force calls.

See [[file:../howto/choose-driver.org][choose a driver]].

* Classical (values only)

- =Boltzmann(t_init, sigma)= :: Logarithmic cooling + Gaussian + Metropolis.
- =Fast(t_init, gamma)= :: Reciprocal cooling + Cauchy + Metropolis.
- =Gsa(t_init, =q_v=, q_a)= :: =Tsallis= cooling + =Tsallis= visit + =Tsallis= accept.

All called via =run(obj, low, high, preset, n_epochs, steps_per_epoch, seed, x0=None)=.
Each move is mirror-reflected into =[low, high]= and the neighbourhood is the
box, so =obj= is only evaluated inside it. =x0= starts the walk at a given
point; without it the start is a uniform draw. The start costs one
evaluation, so a run makes =1 + n_epochs * steps_per_epoch= calls.
=run_qmc= and =global_optimize= take =x0= as well.
=low=, =high= and =x0= may be any array-like of one shape, flattened in C order.
A coordinate with =low == high= stays fixed. A NaN objective value counts as
worse than every number, =+inf= included, so it is never kept as the best.

* i-PI driver client

=IPIDriver= is the client side of the i-PI socket protocol.
Its header is =CppCore/rgpot/IPIPot/IPIDriver.hpp=.
It connects to a server and answers each geometry with an rgpot evaluation.
=IPIPot= is the server side.
[[file:../howto/ipi.org][The i-PI how-to]] shows both directions.
The protocol is Ceriotti, More and Manolopoulos, CPC 185, 1019 (2014).
The i-PI 3.0 paper is J Chem Phys 161, 062504 (2024).
The class is built with =-Dwith_ipi= (CMake =RGPOT_WITH_IPI=).
The default, =auto=, builds it everywhere except Windows.

On the wire, lengths are bohr, energies hartree and forces hartree/bohr.
The cell arrives with its lattice vectors in the columns.
The driver transposes it to rgpot rows.
The virial is the extensive tensor =W = -sigma V= in hartree, row-major.
That is the tensor =IPIPot= reads.

** =rgpot::IPIDriverConfig=

- Inputs :: =address= (default empty) and =species= (default empty).
  =unix_prefix= (default =/tmp/ipi_=).
  =connect_timeout_s= (default 30.0) and =timeout_s= (default 0.0).
  =cutoff= (default 0.0) and =stress_step= (default 0.0).
  =extras_json= (default true).
  =address= is =unix:/absolute/path=, =unix:<name>=, =tcp:<host>:<port>= or
  =tcp:<port>=.
  =unix:<name>= connects to =unix_prefix= followed by the name.
  =tcp:<port>= uses the host 127.0.0.1.
  =species= holds one atomic number per atom, in the server's atom order.
- Units :: =connect_timeout_s= and =timeout_s= are seconds.
  =timeout_s= bounds each message, and 0 waits forever.
  =cutoff= is in Angstrom.
  It is the range used to tile a thin periodic cell and to pad an open box.
  =stress_step= is a dimensionless strain.
  Above 0 it turns on the central-difference virial for a stress-free kernel.
- Outputs :: a plain struct read by =IPIDriver=.
- Errors :: =IPIDriver= throws =std::invalid_argument= for these values.
  An empty species list or an atomic number outside 1 to 118.
  More atoms than the protocol limit of 10^7.
  An address without a =unix:= or =tcp:= prefix, or an empty UNIX address.
  A UNIX name containing =/=, or a path too long for the socket address.
  A missing, out-of-range or zero port.
  A timeout or cutoff that is negative or not finite.
  A =stress_step= outside [0, 0.1).

** =rgpot::IPIDriver=

#+attr_rgpot: signature
#+begin_src cpp
IPIDriver(const IPIDriverConfig &config, IPIEvaluator evaluate);
#+end_src

- Inputs :: =config=, an =rgpot::IPIDriverConfig=.
  =evaluate=, an =rgpot::IPIEvaluator=.
  =IPIEvaluator= is =std::function<void(const ForceInput &, ForceOut *)>=.
  It gets the positions, the atomic numbers and the cell.
  Its =ForceOut= arrives with zeroed forces.
  The =eval= member of =rgpot::spec::Built= fits it.
  That struct is what =engines/pot_spec.hpp= returns.
  A lambda around any potential's =forceImpl= fits it too.
- Units :: the evaluation sees Angstrom, with the cell vectors as rows.
  It returns eV, eV/Angstrom and any Cauchy stress in eV/Angstrom^3.
  The driver sends hartree, hartree/bohr and the virial =-sigma V= in hartree.
- Outputs :: a driver that has checked its configuration and not connected.
- Errors :: =std::invalid_argument= for an empty =evaluate=.
  The configuration errors are those of =rgpot::IPIDriverConfig=.

The driver follows the reference =driver.py=.
=STATUS= gets =NEEDINIT= before the first =INIT=.
It gets =HAVEDATA= while a result waits for =GETFORCE=, and =READY= otherwise.
=INIT= carries a bead index and an init string, and both are kept.
=POSDATA= carries the cell, its inverse and the positions.
Its atom count must equal the length of =species= on every message.
=GETFORCE= gets =FORCEREADY=, the energy, the atom count and the forces.
The virial and the extra string follow.
=EXIT= closes the connection and ends =run()=.

ASE sends a singular cell (zero volume) for a cluster.
The driver evaluates such a geometry in a cube at least 100 Angstrom wide.
The cube is also wider than twice the cluster extent plus =cutoff=.
This is the open box of the PLUMED and GROMACS hosts.
A periodic cell can be no wider than twice =cutoff= along an axis.
The driver tiles such a cell along that axis.
The energy is divided by the number of copies.
The forces of the first copy are sent.

An evaluation may report no stress while =stress_step= is above 0.
The virial is then a central difference of the energy under strain.
Positions and cell are deformed together by =stress_step=.
That costs twelve extra evaluations per geometry.
Otherwise a missing stress is sent as a zero virial.

=extras_json= sends ={"virial": "<source>", "virial_units": "hartree"}=.
The source is =kernel=, =finite_difference= or =none=.
Without it the extra string is empty.

** =rgpot::IPIDriver::connect=

#+attr_rgpot: signature
#+begin_src cpp
void connect();
#+end_src

- Inputs :: none.
- Units :: the retry window =connect_timeout_s= is in seconds.
- Outputs :: an open connection; a call while connected does nothing.
  A refused, reset or missing socket is retried every 50 ms.
  The retries stop when =connect_timeout_s= ends.
  So the driver may start before the server listens.
- Errors :: =std::runtime_error= when the window ends without a connection.
  The same when the error cannot be retried or a TCP host does not resolve.

** =rgpot::IPIDriver::step=

#+attr_rgpot: signature
#+begin_src cpp
bool step();
#+end_src

- Inputs :: none.
- Units :: =timeout_s= in seconds bounds the message.
- Outputs :: true after a =STATUS=, =INIT=, =POSDATA= or =GETFORCE= message.
  False after =EXIT=, which closes the connection.
- Errors :: =std::runtime_error= when the driver is not connected.
  The same on a timeout or a disconnect (=i-PI server disconnected=).
  The same on an unexpected header.
  The same on an =INIT= string length outside 0 to 2^20.
  The same on a =POSDATA= atom count that differs from =species=.
  The same on non-finite positions or cell values.
  The same on =GETFORCE= before =POSDATA=.
  An exception from the evaluation propagates unchanged.
  Every error closes the connection.

** =rgpot::IPIDriver::run=

#+attr_rgpot: signature

void run();
#+end_src

- Inputs :: none.
- Units :: those of =connect= and =step=.
- Outputs :: returns after =EXIT=.
- Errors :: those of =connect= and =step=.

** =rgpot::IPIDriver::close=

#+attr_rgpot: signature
#+begin_src cpp
void close() noexcept;
#+end_src

- Inputs :: none.
- Units :: none.
- Outputs :: the connection is closed without a message.
  The next connection starts at =NEEDINIT=.
  The destructor calls it.
- Errors :: none.

This example compiles here.
Running it needs a server listening on =/tmp/ipi_rgpot=.
=IPIPot= with =unix:rgpot= is one; ASE's =SocketIOCalculator= is another.

#+attr_rgpot: compile
#+begin_src cpp
#include "rgpot/IPIPot/IPIDriver.hpp"
#include "rgpot/LennardJones/LJPot.hpp"

#include <cstdio>

int main() {
  rgpot::LJPot pot({.u0 = 0.0104, .cutoff = 8.5, .psi = 3.40});
  rgpot::IPIDriverConfig cfg;
  cfg.address = "unix:rgpot";
  cfg.species.assign(108, 18);
  cfg.cutoff = 8.5;
  rgpot::IPIDriver driver(cfg, [&pot](const rgpot::ForceInput &in,
                                      rgpot::ForceOut *out) {
    pot.forceImpl(in, out);
  });
  driver.run();
  std::printf("served %llu geometries\n",
              static_cast<unsigned long long>(driver.evaluations()));
  return 0;
}
#+end_src

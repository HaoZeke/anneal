* C++ engine-backed potentials

These potentials call an external program or library: a quantum-chemistry
engine, a tight-binding library, a machine-learned model or a socket peer.
Every class derives from =rgpot::Potential<Derived>=, except the dlopen
frontends =XTBDlopen= and =MetatomicDlopen=, which have no base class and
declare =forceImpl= themselves.
The members they inherit (=forceImpl=, =forceBatch=, =caps=, the call operator)
are described with the base class; this page lists only the members each class
declares itself.
The in-process kernels are in [[file:cpp_potentials.org][C++ potentials]].

Unless an entry says otherwise, a class takes positions and the cell in Angstrom
(cell vectors as rows) and returns the energy in eV and the forces in
eV/Angstrom. Engines that work in atomic units get positions converted with =units::ANGSTROM_TO_BOHR=, the energy with =units::HARTREE_TO_EV= and gradients with =units::NEG_GRAD_TO_FORCE= (minus Hartree/bohr
to eV/Angstrom), all from =CppCore/rgpot/units.hpp=.

** How each class finds its engine

The dlopen frontends try a list of library names in order.
A bare name is resolved by the dynamic linker search path.
=CP2KPot=, =CPMDPot=, =MOPACPot=, =NWChemPot=, =XTBDlopen= and =MetatomicDlopen=
stop at the first library that opens and then check its symbols, so a library
with missing symbols ends the search.
=LammpsPot=, =GromacsPot= and =OpenMMPot= skip a library that lacks the symbols
and try the next name.

| Class        | Library                 | Search order                                                                                  |
|--------------+-------------------------+-----------------------------------------------------------------------------------------------|
| =CP2KPot=    | =libcp2kc_rgpot=        | =enginePath=, =CP2KC_LIBRARY=, =RGPOT_CP2K_ENGINE=, =libcp2kc_rgpot.so=, =./libcp2kc_rgpot.so= |
| =CPMDPot=    | =libcpmdc=              | =enginePath=, =CPMDC_LIBRARY=, =RGPOT_CPMDC_ENGINE=, =RGPOT_CPMD_ENGINE=, =libcpmdc.so=, =./libcpmdc.so= |
| =MOPACPot=   | =libmopacc=             | =Config::engine_path=, =MOPACC_LIBRARY=, =RGPOT_MOPACC_ENGINE=, =libmopacc.so=, =./libmopacc.so= |
| =NWChemPot=  | =libnwchemc=            | =enginePath=, =NWCHEMC_LIBRARY=, =RGPOT_NWCHEMC_ENGINE=, =RGPOT_NWCHEM_ENGINE=, =libnwchemc.so=, =./libnwchemc.so= |
| =SkalaPot=   | =libnwchemc=            | as =NWChemPot=                                                                                |
| =LammpsPot=  | engine plugin           | =engine_path= alone when set; else =RGPOT_LAMMPS_ENGINE=, =LAMMPS_ENGINE=, =liblammps_engine.so=, =liblj_engine.so= |
| =GromacsPot= | =rgpot_md_native_force= | =engine_path= alone; empty means the in-process Lennard-Jones                                 |
| =OpenMMPot=  | =rgpot_md_native_force= | as =GromacsPot=                                                                               |
| =XTBDlopen=  | =libxtb_engine=         | =engine_path= alone when set; else =RGPOT_XTB_ENGINE=, =XTB_ENGINE=, =libxtb_engine.so=, then each directory of =EON_POTENTIALS_PATH= and =RGPOT_ENGINE_PATH= |
| =MetatomicDlopen= | =libmetatomic_engine= | =engine_path=, =RGPOT_METATOMIC_ENGINE=, =METATOMIC_ENGINE=, =libmetatomic_engine.so=, then each directory of =EON_POTENTIALS_PATH= and =RGPOT_ENGINE_PATH= |

After the =.so= names the CP2K, CPMD, MOPAC and NWChem lists also try the
=.dylib= names (bare and with =./=), and CPMD, MOPAC and NWChem try =cpmdc.dll=,
=mopacc.dll= and =nwchemc.dll=.
=LammpsPot= uses =.dylib= names on macOS and =.dll= names on Windows instead of
=.so=.
=XTBDlopen= and =MetatomicDlopen= try the =.dylib= name before the =.so= name on
macOS, and on Windows try =xtb_engine.dll= and =libxtb_engine.dll=
(=metatomic_engine.dll= and =libmetatomic_engine.dll=) in place of the =.so=
name.
=TBLitePot= and =XTBPot= link =libtblite= and =libxtb= at build time.
=MetatomicPot= and =UmaPot= link libtorch.
=XTBDlopen= and =MetatomicDlopen= are in every =librgpot= and need neither;
their engine libraries carry the C ABIs in
[[file:engine_abi.org][Engine C ABI]].
=IPIPot= opens a socket and waits for a driver.

None of the dlopen constructors throw when the library is missing.
They record the reason, =available()= returns false, and the first force throws
=std::runtime_error= with that reason.
The exceptions are =LammpsPot=, =GromacsPot= and =OpenMMPot= with an
=engine_path=: their constructors throw =std::runtime_error= when no library
opens.
=XTBDlopen= and =MetatomicDlopen= also throw from the constructor, so
=available()= is true for every object they construct.

** CP2K

*** =rgpot::CP2KPot=

#+attr_rgpot: signature
#+begin_src cpp
CP2KPot();
explicit CP2KPot(const ::CP2KParams::Reader &params);
#+end_src

- Inputs :: optional =CP2KParams= (Cap'n Proto); the default constructor uses
  the schema defaults.
- Units :: positions and cell in Angstrom, energy in eV, forces in
  eV/Angstrom. The class converts positions and cell to bohr, and the shim's Hartree energy and Hartree/bohr
  forces back.
  The shim returns forces, so there is no sign change.
- Outputs :: a potential that runs CP2K Quickstep through the =libcp2kc_rgpot=
  shim.
- Errors :: the constructors do not throw when the shim is missing; see
  =loadError=.
  A force throws =rgpot::CP2KScfError= (a =std::runtime_error=) when the SCF
  does not converge, on every rank of the calculator.
  Any other failure throws =std::runtime_error=: shim not loaded, a bad
  =inputTemplate=, =nAtoms= of zero, a null buffer, a refused calculator
  binding, the shim refusing the deck or the orbital key, or a nonzero shim
  status.

The shim must report =cp2kc_abi_version()= equal to =CP2KC_ABI_VERSION= and
export the session functions, and =cp2kc_available()=, when exported, must be
nonzero.
The deck is rendered from the params (or from =inputTemplate=, which must
contain both =@RGPOT_COORD@= and =@RGPOT_CELL@=) on the first force and again
whenever the sequence of atomic numbers changes.
A non-empty =dataDir= sets =CP2K_DATA_DIR= before the session starts.
The build option is =-Dwith_cp2k=enabled= and it needs =-Dwith_rpc=true=.

*** =rgpot::CP2KPot::setParams=

#+attr_rgpot: signature
#+begin_src cpp
bool setParams(const ::CP2KParams::Reader &params);
#+end_src

- Inputs :: =params=, the next =CP2KParams=.
- Units :: as the message fields (=cutoffRy= in Rydberg); the call converts
  nothing.
- Outputs :: true when the shim is loaded and the params are usable.
  False when the shim cannot be loaded, or =inputTemplate= lacks
  =@RGPOT_COORD@= or =@RGPOT_CELL@=.
  The params are stored either way.
- Errors :: no exception of its own; failures are reported by the return value
  and =loadError=.

The live session is destroyed when the serialized params differ or =enginePath=
changes; otherwise it keeps its wavefunctions.
The shim is loaded again when it was not loaded or =enginePath= changed.

** CPMD

*** =rgpot::CPMDPot=

#+attr_rgpot: signature
#+begin_src cpp
CPMDPot();
explicit CPMDPot(const ::CPMDParams::Reader &params);
#+end_src

- Inputs :: optional =CPMDParams= (Cap'n Proto); the default constructor uses
  the schema defaults.
- Units :: positions in Angstrom, energy in eV, forces in
  eV/Angstrom, stress in eV/Angstrom^3.
  With the session ABI, rgpot sends a =ForceInput= tagged =angstrom= and =eV=
  and the engine returns those units.
  With the one-shot ABI, positions go in Angstrom and the class converts the
  Hartree energy and the
  Hartree/bohr gradient. It also converts a Hartree/bohr^3 stress when the
  engine exports =cpmdc_last_stress= and reports a valid tensor.
- Outputs :: a potential that runs CPMD through =libcpmdc=.
- Errors :: the constructors do not throw when the engine is missing.
  A force throws =std::runtime_error= when the engine is not available, =nAtoms=
  is zero, a buffer is null, the calculator binding was refused, the orbital key
  is refused, the engine reports failure, or the returned =PotentialResult= is
  malformed or has the wrong force count.

The engine must export the feature discovery functions (=cpmdc_feature_count=,
=cpmdc_feature_table=, =cpmdc_feature_find=) and either the session result ABI
or =cpmdc_energy_gradient= with =cpmdc_set_params=.
A non-empty =cpmdRoot= sets =CPMD_ROOT=.
The one-shot ABI does not receive the cell.
The class is built when =-Dwith_rpc=true=.

- Outputs :: true when the engine is loaded and accepts the params (a session is
  created, or =cpmdc_set_params= returns 0).
- Errors :: no exception of its own; a false return covers a missing engine and

The engine is loaded again when it was not loaded or =enginePath= changed.
A live session is kept when the engine path and the serialized params are
unchanged.

** NWChem

*** =rgpot::NWChemPot=

#+attr_rgpot: signature
#+begin_src cpp
NWChemPot();
explicit NWChemPot(const ::NWChemParams::Reader &params);
#+end_src

- Inputs :: optional =NWChemParams= (Cap'n Proto); the default constructor uses

#+attr_rgpot: compile requires=has_rpc
#+begin_src cpp
#include "rgpot/NWChemPot/NWChemPot.hpp"

#include <capnp/message.h>

#include <cstdio>
#include <string>

int main() {
  ::capnp::MallocMessageBuilder msg;
  auto params = msg.initRoot<::NWChemParams>();
  params.setTheory("scf");
  params.setBasis("6-31g*");
  params.setCharge(0);
  params.setMultiplicity(1);

  rgpot::NWChemPot pot(params.asReader());
  std::string message;
  ::capnp::MallocMessageBuilder cfg_msg;
  auto cfg = cfg_msg.initRoot<::PotentialConfig>();
  cfg.setNwchem(params.asReader());
  if (!pot.setPotentialConfig(cfg.asReader(), &message)) {
    std::fprintf(stderr, "%s\n", message.c_str());
    return 1;
  }
  return 0;
}
#+end_src

*** =rgpot::TBLitePot=

#+attr_rgpot: signature
#+begin_src cpp
TBLitePot();

#+end_src

- Units :: positions in Angstrom, energy in eV, forces in

** xtb

*** =rgpot::XTBConfig=

- Inputs :: =method= (=GFNMethod::GFNFF=, =GFN0xTB=, =GFN1xTB= or =GFN2xTB=;
  default =GFN2xTB=), =accuracy= (default 1.0),
  =electronic_temperature= (default 300.0), =max_iterations= (default 250),
  =charge= (default 0.0), =uhf= (unpaired electrons, default 0),
  =warm_move= (default 1.0), =warm_min_gap= (default 1.0).
- Units ::
  =electronic_temperature= in K; =charge= in elementary charges; =warm_move= in
  Angstrom; =warm_min_gap= in eV; the other fields have no unit.
- Outputs :: a plain struct read by =XTBPot= and, inside =XTBDlopenConfig=, by
  =XTBDlopen=.
- Errors :: neither class checks the values.
  A value xtb rejects fails the force with =std::runtime_error=.
  Zero or a negative =warm_move= disables wavefunction reuse.
  Zero or a negative =warm_min_gap= reuses the wavefunction at any gap.

*** =rgpot::XTBDlopenConfig=

- Inputs :: =xtb= (an =XTBConfig=, default-constructed), =engine_path= (default
  empty).
- Units :: as =XTBConfig=; =engine_path= none.
- Outputs :: a plain struct read by =XTBDlopen=, the frontend that loads
  =libxtb_engine= instead of linking libxtb.
- Errors :: =XTBDlopen= throws
  =std::runtime_error= when a non-empty =engine_path= has no directory
  separator, when no candidate library opens, or when the library lacks the C
  ABI or reports another ABI version.

A non-empty =engine_path= is the only candidate.
An empty one searches =RGPOT_XTB_ENGINE=,
=XTB_ENGINE=, the platform name (=libxtb_engine.so= on Linux), then
=libxtb_engine.so= in each directory of =EON_POTENTIALS_PATH= and =RGPOT_ENGINE_PATH=.

*** =rgpot::XTBPot=

#+attr_rgpot: signature
#+begin_src cpp
XTBPot();
explicit XTBPot(const XTBConfig &config);
#+end_src

- Inputs :: =config=, an =rgpot::XTBConfig=; the default constructor, where
  there is one, uses its defaults.
- Units :: positions in Angstrom, energy in eV, forces in
  eV/Angstrom, stress in eV/Angstrom^3.
  The class sends positions and cell in bohr and converts the Hartree energy,
  the Hartree/bohr gradient and the Hartree virial divided by the cell volume.
  The molecule is created non-periodic in all three directions; stress is set
  when the cell volume is positive.
- Outputs :: a potential that calls the linked libxtb C API.
- Errors :: =std::runtime_error= from the constructor when the xtb environment,
  calculator or results cannot be created.
  A force throws =rgpot::SccNotConverged=, a =std::runtime_error=, when the SCC
  does not converge and the rescue below does not help, and
  =std::runtime_error= when the handles are missing, =xtb_newMolecule= fails,
  another single point failure occurs, or the energy or gradient is not finite.
  After such a failure the handles are replaced.

A new composition rebuilds the molecule.
A force starts the SCC from the previous wavefunction when the composition is
unchanged, no atom moved further than =warmMove()=, and the HOMO-LUMO gap of
that wavefunction is at least =warmMinGap()=.
A single point started that way that does not converge, or whose gap falls below
=warmMinGap()=, is run again from xtb's own guess.
GFN-FF has no orbitals, so its gap never blocks reuse.
The first single point of a force runs at most 48 SCC iterations, or
=max_iterations= when that is smaller.
An SCC that does not converge is retried at 1000, 3000 and 5000 K (those above
the configured temperature) and then evaluated again at the configured
temperature.
The build option is =-Dwith_xtb=true=.

*** =rgpot::XTBPot::reset=

#+attr_rgpot: signature
#+begin_src cpp
void reset();
#+end_src

*** =rgpot::IPIPot=

#+attr_rgpot: signature
#+begin_src cpp
explicit IPIPot(const IPIConfig &config);
#+end_src

- Inputs :: =config=, an =rgpot::IPIConfig=; the default constructor, where
  there is one, uses its defaults.
- Units :: positions and cell in Angstrom, energy in eV, forces in
  eV/Angstrom, stress in eV/Angstrom^3.
  On the wire the class sends bohr (the cell with lattice vectors in columns,
  and its inverse) and converts the driver's Hartree energy,
  Hartree/bohr forces and Hartree virial; the stress is -W/V.
  =timeout_s= is in seconds and covers one whole force call, including the wait
  for the driver to connect.
- Outputs :: a potential that binds the socket at construction and evaluates
  through one i-PI driver.
- Errors ::
  =std::invalid_argument= from the constructor for a bad address, port or timeout or a UNIX path that is too long; =std::runtime_error=
  when the socket cannot be bound or listened on.
  A force throws
  =std::invalid_argument= for missing buffers, zero atoms, more atoms than the protocol limit, non-finite positions or cell, or a singular cell, and =std::runtime_error=
  on a timeout, a disconnect, an unexpected header, a driver that does not
  become READY, or a mismatched atom count.
  After a failed exchange the connection is closed and the next force waits for
  a new driver.

Atomic numbers are not sent; the driver keeps its own species list.
The destructor sends EXIT.
The force call does not write =ForceOut::stress=; read it with =copyStress=.
The build option is =-Dwith_ipi=; its default, =auto=, builds the class

#include "rgpot/IPIPot/IPIPot.hpp"

#include <cstdio>
#include <vector>

  std::printf("driver should connect to %s\n", pot.endpoint().c_str());

** LAMMPS, GROMACS and OpenMM

These three classes evaluate the shifted 12-6 Lennard-Jones potential described
by =ExternalLjConfig=.
The C entry points with the same names as the three factory functions are in
=CppCore/rgpot/ExternalPot/external_potentials.h=.

*** =rgpot::ExternalLjConfig=

- Inputs :: =u0= (well depth, default 1.0), =cutoff= (truncation distance,
  default 8.0), =psi= (zero crossing, default 1.0), =engine_path= (default
  empty).
- Units :: =u0= in eV; =cutoff= and =psi= in Angstrom; =engine_path= none.
- Outputs :: a plain struct read by the constructors of =LammpsPot=,
  =GromacsPot= and =OpenMMPot=.
- Errors :: those constructors throw =std::invalid_argument= when =u0=, =cutoff=
  or =psi= is not positive and finite.
  An
  =engine_path= that does not open, or lacks the required symbols, makes them throw =std::runtime_error=.

For =LammpsPot= an empty
=engine_path= searches =RGPOT_LAMMPS_ENGINE=, =LAMMPS_ENGINE=,
=liblammps_engine= and =liblj_engine=.
For =GromacsPot= and =OpenMMPot= an empty =engine_path= evaluates the potential
in process.

*** =rgpot::GromacsPot=

#+attr_rgpot: signature
#+begin_src cpp
explicit GromacsPot(const ExternalLjConfig &config);
#+end_src

- Inputs :: =ExternalLjConfig=.
- Units :: =u0= in eV, =cutoff= and =psi= in Angstrom; positions in Angstrom,
  energy in eV, forces in eV/Angstrom. The constructor stores =u0= in kJ/mol and
  the lengths in nm.
  With an =engine_path=, positions and cell go to =rgpot_md_native_force= in nm,
  and the kJ/mol energy, the (kJ/mol)/nm forces and the variance (kJ/mol
  squared) come back converted.
  The factors are in =CppCore/rgpot/ExternalPot/md_units.hpp=.
- Outputs :: a potential that evaluates in process with =rgpot::LJPot= when
  =engine_path= is empty, or through the native library otherwise.
  =caps().stress= is true only for the in-process path.
- Errors ::
  =std::invalid_argument= when =u0=, =cutoff= or =psi= is not positive and finite; =std::runtime_error=
  when the library does not open, lacks =rgpot_engine_create=,
  =rgpot_engine_destroy= or =rgpot_md_native_force=, or =rgpot_engine_create=
  fails.
  A force throws
  =std::invalid_argument= for missing buffers and =std::runtime_error= when
  =rgpot_md_native_force= returns nonzero.

The three classes are built in every configuration except
=-Dwith_rpc_client_only=true=.

*** =rgpot::OpenMMPot=

#+attr_rgpot: signature
#+begin_src cpp

#+end_src

- Inputs :: =ExternalLjConfig=.
- Units :: as =rgpot::GromacsPot=.
- Outputs :: as =rgpot::GromacsPot=; the two classes share one implementation.

This example runs here because an empty =engine_path= evaluates in process.

#+attr_rgpot: run link=rgpot
#+begin_src cpp
#include "rgpot/ExternalPot/ExternalPot.hpp"

#include <array>
#include <cstdio>
#include <vector>

int main() {
  rgpot::ExternalLjConfig cfg;
  cfg.u0 = 1.0;
  cfg.cutoff = 8.0;
  cfg.psi = 1.0;
  auto pot = rgpot::rgpot_gromacs_potential(cfg);

  rgpot::types::AtomMatrix positions(2, 3);
  for (int i = 0; i < 2; ++i)
    for (int k = 0; k < 3; ++k)
      positions(i, k) = 0.0;
  positions(1, 0) = 1.5;
  std::vector<int> numbers{1, 1};
  std::array<std::array<double, 3>, 3> box{{{20, 0, 0}, {0, 20, 0}, {0, 0, 20}}};
  auto [energy, forces, variance] = (*pot)(positions, numbers, box);
  std::printf("u0 = %g kJ/mol, E = %.10f eV, Fx0 = %.10f eV/A\n",
              pot->nativeU0(), energy, forces(0, 0));
  return 0;
}

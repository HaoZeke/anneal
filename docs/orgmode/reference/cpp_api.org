* C++ API

The C++ API in =include/rgpot/= wraps the C ABI of =rgpot-core= in move-only
handles.
=rgpot/rgpot.hpp= includes =errors.hpp=, =potential.hpp= and =types.hpp=, and
=rpc_client.hpp= only when =RGPOT_HAS_RPC= is defined.
It does not include =CppCore/rgpot/Potential.hpp=; each potential header (for
example =rgpot/LennardJones/LJPot.hpp=) brings in =rgpot::PotentialBase= and
=rgpot::Potential=.
Most wrapper methods pass the C status code to an internal check that throws
=rgpot::Error= for any status other than =RGPOT_SUCCESS=.
The exceptions are stated in each entry: =invalidate_hvp= and =reset_hvp_counts=
call C functions that return nothing, and the factories and the =InputSpec= and
=CalcResult= constructors check nothing.
The wrappers call the C functions of =rgpot-core=, which a Meson build links
only with =-Dwith_rust_core=true=.
Meson defines =RGPOT_HAS_RPC= only when =with_rust_core= is on together with
=with_rpc= or =with_rpc_client_only=.

The handles do not convert units.
Positions, cell, energy and forces are in the units of the wrapped potential.
The built-in potentials use Angstrom, eV and
eV/Angstrom (=CppCore/rgpot/units.hpp=).

** include/rgpot/errors.hpp

*** =rgpot::Error=

#+attr_rgpot: signature
#+begin_src cpp
explicit Error(const std::string &msg,
               rgpot_status_t status = RGPOT_INTERNAL_ERROR);
#+end_src

- Inputs :: =msg=, the text that =what()= returns, and =status=, the code the C
  API returned (default =RGPOT_INTERNAL_ERROR=).
- Units :: none.
- Outputs :: an exception derived from =std::runtime_error=.
- Errors :: none; the constructor has no failure path.

*** =rgpot::Error::status=

#+attr_rgpot: signature
#+begin_src cpp
[[nodiscard]] rgpot_status_t status() const noexcept;
#+end_src

- Inputs :: none.
- Units :: none.
- Outputs :: the status the C API returned, so a caller tells
  =RGPOT_SCC_NOT_CONVERGED= from other failures.
  An =Error= built without a status holds =RGPOT_INTERNAL_ERROR=.
- Errors :: none.

The wrappers build =msg= from a category prefix and the =rgpot_last_error()=
text, or "unknown error" when that pointer is NULL.
The prefixes are "invalid parameter: " for =RGPOT_INVALID_PARAMETER=, "RPC
error: " for =RGPOT_RPC_ERROR=, "buffer size error: " for
=RGPOT_BUFFER_SIZE_ERROR=, "SCC not converged: " for =RGPOT_SCC_NOT_CONVERGED=,
"no Taylor jet: " for =RGPOT_NO_JET=, "Taylor jet branch: " for
=RGPOT_JET_BRANCH=, "Taylor jet domain: " for =RGPOT_JET_DOMAIN=, and "internal
error: " for =RGPOT_INTERNAL_ERROR= and any other code.
Every category throws the same type, =rgpot::Error=.

** include/rgpot/types.hpp

*** =rgpot::InputSpec=

#+attr_rgpot: signature
#+begin_src cpp
InputSpec(size_t n_atoms, double *pos, int *atmnrs, double *box);
InputSpec(std::vector<double> &positions, std::vector<int> &atmnrs, double *box);
#+end_src

- Inputs :: =n_atoms=; =pos= or =positions=, 3*n doubles, row-major xyz per
  atom; =atmnrs=, n atomic numbers; =box=, 9 doubles, the cell vectors as rows.
  The vector overload takes n as =positions.size() / 3=.
- Units :: positions and cell in the length unit of the potential (Angstrom for
  the built-in potentials); atomic numbers and counts have none.
- Outputs :: a move-only object holding an =rgpot_force_input_t= with non-owning
  DLPack tensors over the caller's arrays.
  The arrays are borrowed, not copied, and must outlive the object.
  The destructor frees the tensor metadata, not the arrays.
- Errors :: none; nothing is checked.
  The vector overload does not compare =atmnrs.size()= with n.
  NULL pointers are stored as given and surface as errors from the call that
  reads them.

** include/rgpot/potential.hpp

*** =rgpot::PotentialHandle=

#+attr_rgpot: signature
#+begin_src cpp
explicit PotentialHandle(rgpot_potential_t *handle);
#+end_src

- Inputs :: =handle=, a pointer from =rgpot_potential_new= or
  =rgpot_potential_new_eindir=, or NULL.
- Units :: none.
- Outputs :: a move-only handle that owns =handle= and passes it to
  =rgpot_potential_free= on destruction.
  A moved-from handle holds NULL.
- Errors :: none; a NULL =handle= is stored as given.

*** =rgpot::PotentialHandle::from_impl=

#+attr_rgpot: signature
#+begin_src cpp
template <typename Impl> static PotentialHandle from_impl(Impl &impl);
template <typename Impl>
static PotentialHandle from_impl(Impl &impl, size_t n_atoms,
                                 const int32_t *atomic_numbers,
                                 const double *box_matrix,
                                 const double *bounds_low = nullptr,
                                 const double *bounds_high = nullptr);
#+end_src

- Inputs :: =impl=, an object with
  =forceImpl(const rgpot::ForceInput &, rgpot::ForceOut *)=; the caller keeps
  ownership and must keep it alive while the handle lives.
  The second overload also takes =n_atoms=, =atomic_numbers= (n values),
  =box_matrix= (9 doubles) and optional bounds (3*n doubles each, default -50 and 50 per coordinate when NULL); =rgpot_potential_new_eindir=
  copies them.
- Units :: positions, cell and bounds in the length unit of =impl=.
- Outputs :: a handle whose callback calls =impl.forceImpl= and returns the
  forces as a new owning =[n, 3]= tensor.
  When =Impl= has =hessianVectorImpl=, it is registered as the analytic
  Hessian-vector product.
- Errors :: none thrown by the factory.
  When =n_atoms * 3= overflows, the second overload returns a handle holding
  NULL, and later calls on it throw =rgpot::Error= ("invalid parameter").
  At calculation time an exception from =impl.forceImpl= becomes
  =RGPOT_INTERNAL_ERROR=, or
  =RGPOT_SCC_NOT_CONVERGED= for =rgpot::SccNotConverged=, and missing positions become =RGPOT_INVALID_PARAMETER=;
  the calling method throws =rgpot::Error=.
  The exception's =what()= text is stored with =rgpot_set_last_error=.

The trampoline copies energy, variance and forces from =ForceOut=; it does not
pass stress through.

*** =rgpot::PotentialHandle::from_callback=

#+attr_rgpot: signature
#+begin_src cpp
static PotentialHandle from_callback(rgpot_status_t (*callback)(void *, const rgpot_force_input_t *, rgpot_force_out_t *),
                                     void *user_data, void (*free_fn)(void *) = nullptr);
#+end_src

- Inputs :: =callback=, a C potential callback;
  =user_data=, passed to every call; =free_fn=, called with =user_data= when the
  handle is freed, or =nullptr=.
- Units :: those of =callback=.
- Outputs :: a handle from =rgpot_potential_new=.
- Errors :: none; the result of =rgpot_potential_new= is not checked for NULL.
  A non-success status from =callback= is thrown as =rgpot::Error= by the method
  that called it.

*** =rgpot::PotentialHandle::eam_table=

#+attr_rgpot: signature
#+begin_src cpp
static PotentialHandle eam_table(const std::string &path, int format = RGPOT_EAM_TABLE_AUTO,
                                 bool periodic = true);
#+end_src

- Inputs :: =path=, a funcfl, setfl or Finnis-Sinclair table; =format=, one of
  =RGPOT_EAM_TABLE_AUTO=, =RGPOT_EAM_TABLE_FUNCFL=,
  =RGPOT_EAM_TABLE_SETFL= and =RGPOT_EAM_TABLE_FINNIS_SINCLAIR=; =periodic=,
  nearest image on the cell or a free cluster.
- Units :: positions and cell in Angstrom, energy in eV, forces in eV per
  Angstrom.
- Outputs :: a handle from =rgpot_potential_new_eam_table=: the tabulated EAM
  potential of the Rust core, evaluated in process with no C++ kernel and no
  engine plugin.
  The handle needs a build with =with_rust_core=.
  See [[file:c_abi.org][C ABI of rgpot-core]] for what it evaluates.
- Errors :: throws =rgpot::Error= with status =RGPOT_INVALID_PARAMETER= and a
  message starting =invalid parameter: EAM table:= when the core returns NULL:
  an empty =path=, an unknown =format=, a file that cannot be opened or is not a
  table of that format.
  A calculation on a cell whose face spacing is not above twice the cutoff
  throws the same status from =calculate=.

*** =rgpot::PotentialHandle::hvp=

#+attr_rgpot: signature
#+begin_src cpp
void hvp(const InputSpec &input, const double *direction, double *hv_out,
         double step = 0.0, rgpot_hvp_scheme_t scheme = RGPOT_HVP_AUTO) const;
std::vector<double> hvp(const InputSpec &input,
                        const std::vector<double> &direction,
                        double step = 0.0,
                        rgpot_hvp_scheme_t scheme = RGPOT_HVP_AUTO) const;
#+end_src

- Inputs :: =input=, the geometry; =direction=,
  3*n doubles laid out like the positions; =hv_out=, room for 3*n doubles that
  must not overlap =direction=; =step=, the displacement length, where 0 selects
  =RGPOT_HVP_DEFAULT_STEP=; =scheme=, one of =RGPOT_HVP_AUTO=, =RGPOT_HVP_FORWARD=, =RGPOT_HVP_CENTRAL=, =RGPOT_HVP_ANALYTIC=.
- Units :: =step= in the length unit of the positions; the product is the
  Hessian (energy per length squared, eV/Angstrom^2 for the built-in potentials)
  times =direction=.
- Outputs :: the Hessian-vector product, 3*n doubles: written to =hv_out=, or
  returned as a new vector by the second overload.
- Errors :: throws =rgpot::Error= when =rgpot_potential_hvp= returns a
  non-success status: NULL pointers, an unknown scheme, a negative or non-finite
  step, a non-finite direction value, overlapping buffers, or
  =RGPOT_HVP_ANALYTIC= with no analytic callback give "invalid parameter"; a
  failing force callback gives the category of its status.
  The vector overload throws =rgpot::Error= ("invalid parameter: direction must
  hold 3 * n_atoms values") when =direction.size()= is not 3*n.

With =RGPOT_HVP_FORWARD=, k products at one geometry make k+1 force calls.

*** =rgpot::PotentialHandle::set_fused_settings=

#+attr_rgpot: signature
#+begin_src cpp
void set_fused_settings(const FusedSettingsSpec &spec) const;
#+end_src

- Inputs :: =spec=, the settings of the engine that change its answer at a fixed
  geometry.
- Units :: =charge= in elementary charges, =electronicTemperature= in kelvin.
- Outputs :: none; the settings key the fused cache of the handle (see the C ABI
  reference).
  A request under other settings runs the engine even at positions whose
  outcome, a failure included, is stored.
  A failed energy is not retried at the same bits, so a warm-start retry after a
  failure needs a changed setting.
- Errors :: throws =rgpot::Error= when the core refuses the settings.

*** =rgpot::PotentialHandle::sync_fused_settings=

#+attr_rgpot: signature
#+begin_src cpp
template <ProvidesFusedSettings Impl>
void sync_fused_settings(const Impl &impl) const;
#+end_src

- Inputs :: =impl=, an object whose =fusedSettings()= returns a
  =FusedSettingsSpec=.
- Units :: as =set_fused_settings=.
- Outputs :: none; installs =impl.fusedSettings()=.
  =from_impl= does this once for an =Impl= that has =fusedSettings()= (=XTBPot=
  and =XTBDlopen= do).
  After a setter of the potential, such as =XTBPot::setMaxIterations=, call it:
  the changed setting is a new key.
  Without the call the handle keeps returning the stored failure.
- Errors :: throws =rgpot::Error= when the core refuses the settings.

*** =rgpot::PotentialHandle::fused_error_kind=

#+attr_rgpot: signature
#+begin_src cpp
[[nodiscard]] rgpot_fused_error_kind_t fused_error_kind() const;
#+end_src

- Inputs :: none.
- Units :: none.
- Outputs :: the kind of the failure the fused cache stores,
  =RGPOT_FUSED_SCC_NOT_CONVERGED=,
  =RGPOT_FUSED_ENGINE_FAILED= or =RGPOT_FUSED_INVALID_RESULT=, or
  =RGPOT_FUSED_OK= when it stores none.
- Errors :: none.

An =Impl= whose =forceImpl= throws =rgpot::SccNotConverged= has the failure

Rust core: it stores the exception a force call threw and throws it again, the
same type and message, for the same bits and settings.

** CppCore/rgpot/Potential.hpp: rgpot::Potential

*** =rgpot::Potential=

- Inputs :: the template argument =Derived=, the concrete potential; the
  constructor is inherited from =PotentialBase= and takes a =PotType=.
- Units :: those of =Derived=; the built-in potentials use Angstrom, eV and
  eV/Angstrom.
- Outputs :: a CRTP base whose =operator()= flattens the positions and cell,
  calls =forceImpl= with zeroed outputs, counts the force call, and returns
  energy, forces (n x 3) and variance.
  With =RGPOT_HAS_CACHE= and a cache set, =operator()= returns a cached result
  when the key matches.
- Errors :: =operator()= propagates any exception from =forceImpl=.

*** =rgpot::Potential::forceImpl=

#+attr_rgpot: signature
#+begin_src cpp
virtual void forceImpl(const ForceInput &in, ForceOut *out) const = 0;
#+end_src

- Inputs :: =in.nAtoms=; =in.pos=, 3*n doubles row-major; =in.atmnrs=, n atomic
  numbers; =in.box=, 9 doubles, cell vectors as rows.
- Units :: those of =Derived=; built-in potentials take Angstrom and write eV,
  eV/Angstrom and, for stress, eV/Angstrom^3.
- Outputs :: =out->F=, 3*n force doubles row-major; =out->energy=;
  =out->variance=; =out->stress=, 9 doubles row-major xx..zz; =out->has_stress=,
  0 when no stress was computed.
  =operator()= and =forceBatch= pass =out= zeroed.
- Errors :: defined by each potential; an override may throw with =out= partly
  written.

*** =rgpot::Potential::forceBatchImpl=

#+attr_rgpot: signature
#+begin_src cpp
virtual void forceBatchImpl(const ForceBatch &batch) const;
#+end_src

- Inputs :: =batch=, =batch.nSystems= systems with parallel arrays =batch.in=
  and =batch.out=.
- Units :: as =forceImpl=.
- Outputs :: fills =batch.out[i]= from =batch.in[i]= for every i.
  The default calls =forceImpl= once per system.
  A potential whose =caps().reentrancy= is =Reentrancy::SharedInstance=, and
  whose caps do not set =perImageInstances= or =groupCollective=, spreads those
  systems across the threads =OMP_NUM_THREADS= requests when every system has
  fewer than =rgpot::kTeamMinAtoms= atoms and the call is not already inside a
  team.
  One requested thread, one system, or any system at that atom count or above
  keeps the serial loop, so a large system can take the team itself.
  Each system is evaluated whole, and the bits match that loop.
  Any other potential keeps the serial loop, so per-instance scratch is not
  shared.
- Errors :: the default propagates an exception from =forceImpl=.
  When several slices run, the exception from the lowest numbered slice is the
  one rethrown, after the team joins.

An override must treat the systems as independent and set =caps().batched=.

*** =rgpot::Potential::forceBatch=

#+attr_rgpot: signature
#+begin_src cpp
void forceBatch(const ForceBatch &batch) override;
#+end_src

- Inputs :: =batch=; each =batch.out[i].F= must have room for 3 *
  =batch.in[i].nAtoms= doubles.
- Units :: as =forceImpl=.
- Outputs :: =batch.out[i]= for every system.
  Every slot is zeroed first.
  With =RGPOT_HAS_CACHE= and a cache set, hits are served from the cache and
  only the misses reach =forceBatchImpl=.
  The lookup and the miss batch are built on the calling thread.
- Errors :: propagates any exception from =forceBatchImpl=; the slots stay
  zeroed or partly written.

*** =rgpot::Potential::setCache=

#+attr_rgpot: signature
#+begin_src cpp
void setCache(rgpot::cache::PotentialCache *c) override;
#+end_src

- Inputs :: =c=, a =rgpot::cache::PotentialCache= pointer, or =nullptr= to stop
  caching.
- Units :: none.
- Outputs :: none; stores =c= for =operator()= and =forceBatch=.
  The caller keeps ownership.
- Errors :: none.

Declared only when =RGPOT_HAS_CACHE= is defined.

** CppCore/rgpot/ForceStructs.hpp

*** =rgpot::ForceInput=

- Inputs :: four fields, all =const=, so the struct is filled by aggregate
  initialisation: =nAtoms= (=size_t=), the atom count n; =pos=
  (=const double *=), 3*n positions, row-major xyz per atom; =atmnrs=
  (=const int *=), n atomic numbers; =box= (=const double *=), 9 doubles, the
  three cell vectors as rows (ax ay az bx by bz cx cy cz).
- Units :: =pos= and =box= in the length unit of the potential (Angstrom for the
  built-in potentials); =nAtoms= and =atmnrs= have none.
- Outputs :: none; the struct borrows the caller's arrays and owns nothing.
- Errors :: none; the struct is plain data and nothing is checked.

*** =rgpot::ForceOut=

- Inputs :: =F= (=double *=), a caller-owned buffer with room for 3*n doubles.
- Units :: =F= in the force unit of the potential
  (eV/Angstrom for the built-in potentials); =energy= in its energy unit (eV); =stress= in energy per length cubed (eV/Angstrom^3);
  =variance= as the potential reports it.
- Outputs :: =F=, 3*n forces row-major like the positions; =energy= (=double=);
  =variance= (=double=), 0 when unused; =stress= (=double[9]=), the Cauchy
  stress row-major xx xy xz yx yy yz zx zy zz; =has_stress= (=int=), 0 when the
  potential did not compute stress.
- Errors :: none; the struct is plain data.

Potentials that write stress set =caps().stress=.

*** =rgpot::ForceBatch=

- Inputs :: =nSystems= (=size_t=), the number of systems; =in=
  (=const ForceInput *=), =nSystems= inputs; =out= (=ForceOut *=), =nSystems=
  result slots, where =out[i]= belongs to =in[i]= and =out[i].F= has room for 3 *
  =in[i].nAtoms= doubles.
- Units :: as =ForceInput= and =ForceOut=.
- Outputs :: none; the caller owns both arrays and every buffer they point at.
- Errors :: none; the struct is plain data.

The systems are independent: each has its own atom count, cell and species.

** CppCore/rgpot/CalculatorGroup.hpp

A calculator is one independent evaluation, such as a NEB image or a dimer end;
the ranks of one calculator share a subcommunicator.
=librgpot= never links MPI.
The MPI side is
=librgpot_mpi=, which =bindCalculators= and =calculatorsUseMpi= load with =dlopen= on first use (Meson option =-Dwith_mpi=enabled=).
Until that library is loaded, every function below behaves as a process of one
calculator with one rank.
Running under MPI is described in [[file:mpi.org][MPI]].

*** =rgpot::CalculatorGroup=

- Inputs :: none; a struct of four =int= fields.
- Units :: none.
- Outputs :: =index= (default 0), the calculator this rank belongs to, or -1
  when the bind was refused; =ranks= (default 1), ranks per calculator;
  =rank_in_group= (default 0), this rank within its calculator;
  =world_size= (default 1), the size of =MPI_COMM_WORLD=.
- Errors :: none.

*** =rgpot::addCalculatorHook=

#+attr_rgpot: signature
#+begin_src cpp
void addCalculatorHook(CalculatorHook hook);
#+end_src

- Inputs :: =hook=, a function =int (*)(int ranks_per_calculator)= that returns
  the group index or -1 to refuse the bind.
- Units :: none.
- Outputs :: none; =hook= is called on every rank from each later
  =bindCalculators= that performs a bind.
  A hook already registered is not added twice.
- Errors :: none; a null =hook= is ignored.

*** =rgpot::bindCalculators=

#+attr_rgpot: signature
#+begin_src cpp
CalculatorGroup bindCalculators(int ranks_per_calculator);
#+end_src

- Inputs :: =ranks_per_calculator=; 0 or less means one calculator for the whole
  world.
- Units :: none.
- Outputs :: the =CalculatorGroup= of this rank, also kept for =thisCalculator=.
  With
  =librgpot_mpi= loaded it is collective on =MPI_COMM_WORLD=, calls =MPI_Init=
  when MPI is not up yet, and splits the world.
  Without it, 1 or 0 or less gives index 0 with one rank, and any other value
  gives index -1.
  Registered hooks and communicator adopters are then called; a negative result
  from any of them sets index to -1.
- Errors :: no exception; failure is reported as index -1.
  Index is -1 when the world size is not a multiple of =ranks_per_calculator= or
  is smaller than it, and when a hook or adopter refuses.
  After a bind, a call whose argument equals the stored ranks per calculator
  returns the stored group.
  Any other argument returns a group with index -1 and leaves the stored group
  unchanged.
  An argument of 0 or less is compared as its resolved value (the world size, or
  1 without MPI), so repeating =bindCalculators(0)= returns the stored group.

- Outputs :: the group stored by the last bind; a default =CalculatorGroup=

*** =rgpot::addCalculatorCommAdopter=

#+attr_rgpot: signature

*** =rgpot::publishCalculatorError=

#+attr_rgpot: signature
#+begin_src cpp

#+end_src

- Inputs :: =message=, empty for success; every rank of the calculator calls it
  at the end of a =groupCollective= force call.
- Units :: none.

  and aborts.
  A rank with a message that waits more than 10 seconds for the exchange aborts
  on its own.
  Without =librgpot_mpi=, or when MPI is not initialized, it returns and the
  caller's exception carries the message.

** Example

The build in this tree is configured with =with_rust_core= off, so the
=rgpot-core= symbols that the handles call are not linked; the example is only
compiled.

#+attr_rgpot: compile
#+begin_src cpp
#include <cstdio>

#include "rgpot/LennardJones/LJPot.hpp"
#include "rgpot/rgpot.hpp"

int main() {
  rgpot::LJPot lj;
  auto pot = rgpot::PotentialHandle::from_impl(lj);

  double pos[] = {0, 0, 0, 1.1, 0, 0};
  int atm[] = {1, 1};
  double box[] = {10, 0, 0, 0, 10, 0, 0, 0, 10};
  rgpot::InputSpec input(2, pos, atm, box);

  try {
    rgpot::CalcResult result = pot.calculate(input);
    std::vector<double> forces = result.forces_vec();
    std::printf("E = %.6f, Fx0 = %.6f\n", result.energy(), forces[0]);
  } catch (const rgpot::Error &e) {
    std::printf("%s\n", e.what());
    return 1;
  }
  return 0;
}
#+end_src

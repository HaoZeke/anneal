* Rust API Reference

The =anneal-core= crate provides the typed sampler components, preset drivers, Bayesian pilot and mixer machinery, GLE-Langevin moves, surrogate independence proposals, local polish helpers, and the Rust surfaces behind the Python and C bindings.
Hopping polish (=methods::warm_lbfgs::WarmLbfgs=) holds an =rgmin::Lbfgs=; the two-loop recursion and strong Wolfe search live in that crate.

The API documentation below is generated from the crate source through =sphinxcontrib_rust= and =sphinx-rustdoc-postprocess=, then linked into this site under the same reference tree as the user-facing parameter tables.

* Crate-root re-exports (=anneal_core=)

** Typed algebra, exchange, and free energy

- =AcceptRule= :: acceptance probability trait =(delta_e, T) -> p=.
- =Adapter=, =IdentityAdapter= :: Stan-style windowed step/parameter adaptation trait and no-op adapter.
- =Bias=, =WellTemperedBias= :: cost-augmenting bias trait and Gaussian/collective-variable well-tempered bias.
- =Cooling= :: temperature schedule trait =epoch -> T=.
- =Neighborhood= :: proposal domain symmetry trait.
- =MoveKernel=, =Reflected= :: temperature-indexed proposal trait and box-reflection wrapper.
- =Sampler= :: single-step Markov transition trait over an objective.
- =SaVariant= :: certified L1--L4 simulated-annealing component tuple.

- =BarEstimator= :: Bennett acceptance ratio free-energy estimator.

** Replica-exchange and barrier tempering

- =IndexProcess=, =Ladder=, =ReplicaMove=, =ReplicaTarget=, =SwapScheme=, =TARGET_SWAP_ACCEPT=, =beta_step_for_acceptance=, =biased_swap_log_ratio=, =swap_log_ratio=, =swap_probability= :: bias-aware replica exchange, non-reversible sweep indexing, and barrier-calibrated temperature ladders.

#+begin_src rust
use anneal_core::{
    ANNEAL_VERSION, DEFAULT_HIT_TOL, Ladder, SwapScheme, TARGET_SWAP_ACCEPT,
    beta_step_for_acceptance, energy_hits, qmc_skip_from_seed,
};

assert!(!ANNEAL_VERSION.is_empty());
let ladder = Ladder::from_temperatures(&[1.0, 2.0, 4.0], SwapScheme::DeterministicEvenOdd);
assert_eq!(ladder.len(), 3);
assert!(energy_hits(-10.0 + DEFAULT_HIT_TOL, -10.0, DEFAULT_HIT_TOL));
assert!(qmc_skip_from_seed(7) > 0);
assert!(beta_step_for_acceptance(2.0, TARGET_SWAP_ACCEPT) > 0.0);
#+end_src

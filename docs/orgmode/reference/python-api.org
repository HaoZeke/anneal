==========
Python API
==========
#+end_export

The package is =anneal=. The compiled module underneath it is
=anneal._core=; =python/anneal/__init__.py= re-exports its classes and wraps
most of its functions. Install it with =maturin develop --features python=
(see [[file:../bindings.org][Bindings]]).

* Type stubs

=python/anneal/_core.pyi= describes every class, function and constant of
=anneal._core=, and =python/anneal/py.typed= marks the package as typed. The
stubs are checked against the compiled module by =pytest/test_stubs.py=, which
reads the stub with =ast= and compares it with the module's names, argument
kinds, defaults and class members. The same file runs =mypy.stubtest= when mypy
is installed.

A binding added to =src/python.rs= without a matching stub entry fails that
test. Add the entry in the same commit.

#+begin_src python
from pathlib import Path

import anneal
import anneal._core as core

stub = Path(anneal.__file__).with_name("_core.pyi")
assert stub.is_file()
assert "def cluster_search(" in stub.read_text()
assert set(core.__all__) >= {"cluster_search", "Config", "Ledger"}
#+end_src

* Errors

Every error that =anneal= raises for rejected input derives from
=anneal.AnnealError=, which derives from =ValueError=. An =except ValueError=
clause that worked before keeps working. The classes name what to fix.

- =AnnealError= :: the base class.
- =InvalidArgumentError= :: an argument has a value, length or combination
  the call cannot use. Most checks raise this class.
- =BoundsError= :: a kind of =InvalidArgumentError= for a box that is empty,
  has sides of different lengths, or has a bound that is not finite or not
  ordered.
- =ConfigError= :: =Config.validate_json= or =Config.validate_toml= could not
  read the text. The =key= attribute is =<json>= or =<toml>=.
- =RemovedConfigKeyError= :: a kind of =ConfigError= for a key that a past
  release removed. The =key= attribute holds the dotted path of the key.
- =NoFiniteStartError= :: =cluster_search= found no finite start. The
  =attempts= attribute counts the quenches it tried.
- =FeatureUnavailableError= :: the call needs a Cargo feature that this
  build lacks, such as =ras=True= without =graphkey=.

A wrong type still raises =TypeError=. An exception that an objective raises
passes through unchanged. A missing file raises =OSError=.

#+begin_src python
import numpy as np

import anneal


def f(x):
    return float(np.sum(np.asarray(x) ** 2))


try:
    anneal.run(f, np.ones(1), np.zeros(1), anneal.Boltzmann())
except anneal.BoundsError as err:
    assert isinstance(err, ValueError)
    assert "strictly less" in str(err)
else:
    raise AssertionError("an inverted box must raise")

try:
    anneal.Config.validate_json('{"ring": {"reseed_hops": 1}}')
except anneal.RemovedConfigKeyError as err:
    assert err.key == "ring.reseed_hops"
else:
    raise AssertionError("a removed key must raise")
#+end_src

* Boxes and states

Every function that takes =low= and =high= checks the box before it searches.
Sides of different lengths raise =InvalidArgumentError=, a bound that is NaN
or a =low= above =high= raises =BoundsError=. Neither case reaches Rust
code that would panic: a panic arrives in Python as =PanicException=, which
derives from =BaseException= and skips =except Exception=.

=BasinBias.potential= and =BasinBias.deposit= take a state of =3 * n_points=
coordinates and raise =InvalidArgumentError= for any other length.

The =Bounds= class is built by the =eindir-core= crate. Its constructor still
panics on sides of different lengths, an inverted pair or a negative =slack=.
Check the arrays before you build one, or pass =low= and =high= to the
search functions, which check them.

#+begin_src python
import numpy as np

import anneal

try:
    anneal.polish(
        lambda x: float(np.sum(x**2)),
        lambda x: 2 * x,
        np.ones(2),
        np.zeros(2),
        np.zeros(2),
    )
except anneal.BoundsError:
    pass
else:
    raise AssertionError("an inverted box must raise")

bias = anneal.BasinBias(3)
try:
    bias.potential(np.zeros(8))
except anneal.InvalidArgumentError as err:
    assert "3 * 3 = 9" in str(err)
else:
    raise AssertionError("a state of the wrong length must raise")
#+end_src

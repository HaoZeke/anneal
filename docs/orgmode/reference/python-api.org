#+begin_export rst
=============================
Python API (``anneal``)
=============================
#+end_export

The Python package ``anneal`` exposes the Rust drivers from ``anneal._core`` alongside pure-Python adapters for device arrays, landscape maps, ChemFit sessions, ASE atoms, and TVM FFI tensors.

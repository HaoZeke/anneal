* C++ potentials

Every potential derives from =rgpot::Potential<Derived>=, which derives from
=rgpot::PotentialBase=.
Energies are eV, lengths are Angstrom and forces are eV/Angstrom unless an entry
says otherwise.
This page lists the constructors, their configuration structs and the members
each class adds.
The members every potential inherits (=forceImpl=, =forceBatch=, =caps=,
=setCache=, ...) are on [[file:cpp_api.org][C++ API]].
How the classes fit together is on [[file:architecture.org][Architecture]].

** CppCore/rgpot/Models/ModelPots.hpp: analytic models

*** =rgpot::AnalyticModelPot=

The common =rgpot::Potential= implementation for Eckart, Muller-Brown, modified
Muller-Brown, LEPS H + H2 / H + Cl2 / F + H2, the generic quartic double well
and the coupled proton well.
Forces are minus the energy gradient; all models advertise and implement an
exact Hessian-vector product.

- Inputs :: constructed through one of its concrete model classes.
- Units :: the non-LEPS constructors use eV and Angstrom.
  LEPS evaluates the published hartree/bohr formulas and converts at the rgpot
  boundary.
- Outputs :: a built-in potential with energy, force and analytic HVP calls.
- Errors :: model-specific invalid parameters and nondifferentiable LEPS
  geometries throw.

*** =rgpot::CBEPot=

The optional linked frontend to the external =cbe-pes= H + CH4 library.

- Inputs :: exactly six Cartesian atoms ordered as required by =cbe-pes=.
- Units :: positions in Angstrom, energy in eV, force and HVP result in
  eV/Angstrom.
- Outputs :: energy, force and the external library's analytic Hessian-vector
  product.
- Errors :: throws for the wrong atom count or a non-success =cbe-pes= status.
  It is built only with =with_cbe= / =RGPOT_WITH_CBE= and does not load a local
  PES library.

A force call takes a =rgpot::ForceInput=: =nAtoms=, =pos= (3 * nAtoms doubles, x
y z per atom, Angstrom), =atmnrs= (one atomic number per atom) and =box= (nine
doubles, one cell vector per row, Angstrom).
It writes a =rgpot::ForceOut=: =F= (3 * nAtoms doubles, same layout as =pos=,
eV/Angstrom), =energy= (eV), =variance=, and =stress= with =has_stress=. =stress= is the Cauchy stress in eV/Angstrom^3,
nine entries row-major. A potential that writes it sets =has_stress= to 1, and
to 0 when the cell volume is not positive.

The program below evaluates a Lennard-Jones dimer with the default parameters.
It links against =librgpot=.

#+attr_rgpot: run link=rgpot
#+begin_src cpp
#include <cstdio>

#include "rgpot/LennardJones/LJPot.hpp"

int main() {
  rgpot::LJPot pot({.u0 = 1.0, .cutoff = 15.0, .psi = 1.0});
  const double pos[6] = {0.0, 0.0, 0.0, 1.5, 0.0, 0.0};
  const int z[2] = {18, 18};
  const double box[9] = {40.0, 0.0, 0.0, 0.0, 40.0, 0.0, 0.0, 0.0, 40.0};
  double forces[6] = {};
  rgpot::ForceInput in{2, pos, z, box};
  rgpot::ForceOut out{};
  out.F = forces;
  pot.forceImpl(in, &out);
  std::printf("energy %.6f eV\n", out.energy);
  std::printf("force on atom 1, x: %.6f eV/Angstrom\n", forces[3]);
  return 0;
}
#+end_src

** Configuration structs

Each struct is a plain aggregate with inline defaults.
Construct it with designated initializers and pass it to the constructor of its
class.

*** =rgpot::LJConfig=

- Inputs :: =u0= (well depth, default 1.0), =cutoff= (truncation distance,
  default 15.0), =psi= (zero-crossing distance, default 1.0), =switch_width=
  (width of the quintic switch that ends at =cutoff=, default 0.0, which keeps
  the shifted truncation).
- Units :: =u0= in eV; =cutoff=, =psi= and =switch_width= in Angstrom.
- Outputs :: the parameters of =rgpot::LJPot=.
- Errors :: the constructor throws =std::invalid_argument= when =switch_width=
  is non-zero and not in (0, cutoff]. No other field is checked.

*** =rgpot::LJClusterConfig=

- Inputs :: the fields of =rgpot::LJConfig= with the same defaults: =u0= 1.0,
  =cutoff= 15.0, =psi= 1.0, =switch_width= 0.0.
- Units :: =u0= in eV; =cutoff=, =psi= and =switch_width= in Angstrom.
- Outputs :: the parameters of =rgpot::LJClusterPot=.
- Errors :: the constructor throws =std::invalid_argument= when =switch_width=
  is non-zero and not in (0, cutoff]. A =cutoff= of 0 or less is accepted and
  keeps every pair.

*** =rgpot::MorseConfig=

- Inputs :: =De= (well depth, default 0.7102), =a= (range, default 1.6047), =re=
  (equilibrium distance, default 2.8970), =cutoff= (default 9.5), =switch_width=
  (default 0.0).
  The defaults are the platinum set of the header.
- Units :: =De= in eV, =a= in 1/Angstrom, =re=, =cutoff= and =switch_width= in
  Angstrom.
- Outputs :: the parameters of =rgpot::MorsePot=.
- Errors :: the constructor throws =std::invalid_argument= when =switch_width=
  is non-zero and not in (0, cutoff]. No other field is checked.

*** =rgpot::ZBLConfig=

- Inputs :: =cut_inner= (where the switch starts, default 2.0), =cut_global=
  (truncation distance, default 2.5).
- Units :: Angstrom.
- Outputs :: the parameters of =rgpot::ZBLPot=.
- Errors :: the constructor throws
  =std::invalid_argument= unless 0 < =cut_inner= < =cut_global=.

*** =rgpot::SuttonChenConfig=

- Inputs :: =epsilon= (default 1.0), =c= (default 34.408), =a= (default 1.0),
  =n= (repulsive exponent, default 10), =m= (density exponent, default 8),
  =cutoff= (default 40.0; 0 or less keeps every pair), =periodic= (minimum
  image, default false), =stress= (write the stress, default false).
  The defaults are the reduced platinum and gold 10-8 potential.
- Units :: =epsilon= sets the energy unit and =a= the length unit; =cutoff= is
  in the coordinate unit; =c=, =n= and =m= are dimensionless.
- Outputs :: the parameters of =rgpot::SuttonChenPot=.
- Errors :: the constructor throws =std::invalid_argument= when =n= or =m= is
  below 1, when =a= is not positive, when =epsilon=, =c= or =cutoff= is not
  finite, and when =periodic= is set with a =cutoff= that is not positive.

*** =rgpot::EAMCellConfig=

- Inputs :: none; the struct has no fields.
- Units :: none.
- Outputs :: the argument of =rgpot::EAMPot=, whose element table is built into
  the kernel.
- Errors :: none.

*** =rgpot::EAMTableConfig=

- Inputs :: =path= (the table file, no default), =format=
  (=EAMTableFormat::Funcfl=, =Setfl= or =FinnisSinclair=, default =Setfl=),
  =periodic= (minimum image, default true), =stress= (write the stress, default
  false), =skin= (Verlet skin of the potential's own pair list, default 1.0).
- Units :: none; the table carries its own units, eV and Angstrom for the LAMMPS
  metal files.
  =skin= is in the length unit of the table.
- Outputs :: the parameters of =rgpot::EAMTablePot=.
- Errors :: the constructor throws =std::invalid_argument= when =path= cannot be
  opened, when the file does not parse as =format=, and when =skin= is negative
  or not finite.

*** =rgpot::EMTConfig=

- Inputs :: =rasmussen= (default false): true selects the Rasmussen parameter
  provider of Asap, false the Asap default provider.
- Units :: none.
- Outputs :: the parameters of =rgpot::EMTPot=.
- Errors :: none.

*** =rgpot::WaterConfig=

- Inputs :: =cutoff= (default 8.5), =switching_width= (default 1.0).
  The defaults are the values the eOn wrappers pass.
- Units :: Angstrom.
- Outputs :: the parameters of =rgpot::TIP4PPot=, =rgpot::SPCEPot= and
  =rgpot::TIP4PPtPot=.
- Errors :: none; the constructors do not check the fields.

*** =rgpot::D3Config=

- Inputs :: =damping= (=D3Damping::BJ=, the rational damping, or
  =D3Damping::Zero=; default =BJ=), =functional= (the s-dftd3 method key,
  default ="pbe"=), =atm= (the Axilrod-Teller-Muto three-body term, default
  true).
- Units :: none.
- Outputs :: the parameters of =rgpot::D3Pot=.
- Errors :: the constructor throws
  =std::invalid_argument= for an empty =functional=, and =std::runtime_error=
  when s-dftd3 cannot load damping parameters for it.

*** =rgpot::D4Config=

- Inputs :: =functional= (the dftd4 method key, default ="pbe"=), =charge=
  (total charge, default 0.0), =atm= (the many-body term, default true).
- Units :: =charge= in elementary charges.
- Outputs :: the parameters of =rgpot::D4Pot=.
- Errors :: the constructor throws
  =std::invalid_argument= for an empty =functional=, and =std::runtime_error=
  when dftd4 cannot load damping parameters for it.
  =charge= is not checked.

*** =rgpot::lr::CoulombConfig=

- Inputs :: =method= (=CoulombMethod::Ewald=, =SPME= or =DSF=, default =Ewald=),
  =cutoff= (real-space or DSF cutoff, default 9.0), =alpha= (splitting
  parameter, default 0.30), =kmax= (Ewald reciprocal shell, default 8), =grid=
  (SPME mesh, default 32 32 32),
  =spline_order= (SPME B-spline order, default 6), =short_cutoff= (short list,
  default 4.0), =skin= (default 1.0), =periodic= (default true), =stress=
  (default true).
- Units :: =cutoff=, =short_cutoff= and =skin= in Angstrom; =alpha= in
  1/Angstrom; the others are counts or flags.
- Outputs :: the parameters of =rgpot::lr::CoulombPot=.
  =stress= false skips the strain and lets the SPME mesh run in single
  precision.
- Errors :: the constructor checks no field.
  The force call throws
  =std::invalid_argument= when =cutoff= or =alpha= is not positive, when =kmax= is below 1 with =Ewald=, and when =spline_order=
  is outside 3 to 16 with =SPME=.
  SPME raises a =grid= entry below 4 to 4.

*** =rgpot::lr::DispersionConfig=

- Inputs :: =kind= (=DispersionKind::D3BJ=, =D4=, =MBD= or =QDO=, default
  =QDO=), =functional= (D3 and D4 method key, default ="pbe"=), =atm=
  (three-body term, default true), =charge= (D4 total charge, default 0.0),
  =mbd_beta= (default 0.83), =mbd_a= (default 6.0),
  =mbd_k= (Monkhorst-Pack mesh for periodic MBD, default 4 4 4), =mbd_gamma=
  (one k-point at Gamma instead of the shifted mesh, default false),
  =qdo_scale= (default 1.0), =qdo_legacy= (legacy QDO tables, default false),
  =qdo_damped= (default true), =cutoff= (pair list cutoff, default 15.0), =lib_disp2=,
  =lib_disp3= and =lib_cn= (library real-space cutoffs, default 0.0, which keeps
  the library default),
  =switch_width= (default 0.0, a hard cutoff), =short_cutoff= (default 4.0),
  =skin= (default 1.0), =periodic= (default false).
- Units :: =cutoff=, =switch_width=, =short_cutoff= and =skin= in Angstrom;
  =lib_disp2=, =lib_disp3= and =lib_cn= in bohr; =charge= in elementary charges;
  the others are dimensionless, counts or flags.
- Outputs :: the parameters of =rgpot::lr::DispersionPot=.
- Errors :: the constructor checks no field.
  Invalid values surface as the errors of the force call listed under
  =rgpot::lr::DispersionPot=.

*** =rgpot::lr::NlhConfig=

- Inputs :: =cutoff= (default 2.0), =skin= (default 0.5), =switch_off= (distance
  by which the repulsion is switched off, default 1.5).
- Units :: Angstrom.
- Outputs :: the parameters of =rgpot::lr::NlhPot=.
- Errors :: the constructor throws
  =std::invalid_argument= unless =cutoff= > =switch_off= > 0.
  =skin= is not checked.

*** =.forcePerAtom=

#+attr_rgpot: signature
#+begin_src cpp
void forcePerAtom(const ForceInput &in, ForceOut *out, const PerAtomOut &atoms) const;
#+end_src

- Applies to :: rgpot::EAMTablePot, rgpot::LJClusterPot, rgpot::LJPot,
  rgpot::MorsePot, rgpot::SuttonChenPot, rgpot::ZBLPot
- Inputs :: =in= and =out= as for =forceImpl=; =atoms.energy= (nAtoms doubles or
  null) and =atoms.virial= (6 * nAtoms doubles or null).
- Units :: per-atom energy and per-atom virial in eV.
- Outputs :: fills =out= as =forceImpl= does, then writes the per-atom arrays.
  Each pair term goes half to each atom, and an embedding term goes to its own
  atom.
  Per-atom energies sum to =out->energy=.
  The virial order per atom is xx, yy, zz, yz, xz, xy.
  A null array is skipped.
- Errors :: the exceptions of the class's =forceImpl=.

=rgpot::LJClusterPot= always walks the cells here, so its energy can differ from
=forceImpl= in the last bits.

*** =.locality=

#+attr_rgpot: signature
#+begin_src cpp
[[nodiscard]] Locality locality() const noexcept;
#+end_src

- Applies to :: rgpot::EAMTablePot, rgpot::LJPot, rgpot::MorsePot,
  rgpot::SuttonChenPot
- Inputs :: none.
- Units :: =cutoff= in the length unit of the potential: Angstrom for
  =rgpot::LJPot= and =rgpot::MorsePot=, the unit of =a= for
  =rgpot::SuttonChenPot= and the unit of the table for =rgpot::EAMTablePot=.
- Outputs :: a =rgpot::Locality= from =CppCore/rgpot/Locality.hpp=.
  =cutoff= is the range of each site energy, =pairwise= is true when every
  energy term is a function of one pair distance, and =densities= is the number
  of values per atom that =densityStage= sums and =forceStage= reads.
  =forceRange()= is =cutoff= for a pairwise potential and twice =cutoff=
  otherwise; the atoms within it of an atom set the force on that atom.
  A host that evaluates its own atoms with every atom within =forceRange()= of
  them, free of periodic images, gets the forces, site energies and per-atom
  virials those atoms have in the whole system.
  With =densityStage= and =forceStage= it needs only the atoms within =cutoff=,
  and exchanges =densities= values per atom between the two stages.
  A =cutoff= of 0 declares no finite range.
- Errors :: none.

=rgpot::LJPot= and =rgpot::MorsePot= return their cutoff with =pairwise= set,
and 0 when the cutoff is 0 or less.
=rgpot::SuttonChenPot= and =rgpot::EAMTablePot= return their cutoff as a
many-body range with =densities= 1.
=rgpot::SuttonChenPot= returns 0 when its cutoff is 0 or less, since it then
keeps every pair.

*** =.densityStage=

#+attr_rgpot: signature
#+begin_src cpp
void densityStage(const HalfList &list, double *densities) const;
#+end_src

- Applies to :: rgpot::EAMTablePot, rgpot::SuttonChenPot
- Inputs :: =list=, a =rgpot::HalfList= from =CppCore/rgpot/Staged.hpp=.
  It holds the positions and atomic numbers of the host's =nOwned= atoms
  followed by their copies, =nAtoms= in all, and a half neighbour list over the
  owned atoms in the layout of a LAMMPS =NeighList=.
  =densities= holds =locality().densities= values per atom for all =nAtoms=
  atoms, zeroed by the caller.
- Units :: positions in the length unit of the potential.
  The densities are those of the table for =rgpot::EAMTablePot= and sums of
  \((a/r)^m\) for =rgpot::SuttonChenPot=.
- Outputs :: adds the density of each listed pair to its row atom, and to the
  other atom when that one is owned or =list.newton= is set.
  Pairs beyond the cutoff are skipped, so a list built with a skin works.
  The host completes the sums before =forceStage=: with =newton= it adds the
  values of each copy into its owner, and it copies the values of each owner to
  its copies.
- Errors :: =rgpot::EAMTablePot= throws =std::invalid_argument= when a pair
  within the cutoff has an atomic number in no element line.
  =rgpot::SuttonChenPot= throws nothing.

=rgpot::LJPot= and =rgpot::MorsePot= have no densities; their =densityStage= is
listed with each class.

*** =.forceStage=

#+attr_rgpot: signature
#+begin_src cpp
void forceStage(const HalfList &list, const double *densities, double *forces,
                StageTally *tally) const;
#+end_src

- Applies to :: rgpot::EAMTablePot, rgpot::LJPot, rgpot::MorsePot,
  rgpot::SuttonChenPot
- Inputs :: =list= as for =.densityStage=, and =densities= after the host
  completed them; the pair potentials do not read =densities=.
  =forces= holds 3 * nAtoms doubles, and =tally= is a =rgpot::StageTally= or
  null.
- Units :: the units of =forceImpl=.
- Outputs :: adds the force of each listed pair to its row atom, and the
  opposite force to the other atom when that one is owned or =list.newton= is
  set.
  The many-body potentials take the embedding derivative of both atoms of a pair
  from their densities, so a copy needs the densities of its owner.
  With a tally it adds the host's share of the energy and of the virial W = -V
  sigma, in the order xx, yy, zz, yz, xz, xy.
  That share is all of a pair that only this host lists, half of a pair that
  both hosts list, and the embedding energy of each owned atom.
  =tally->atoms= takes the per-atom split of =.forcePerAtom=; the entries of a
  copy are written only with =newton=, for the host to add to its owner.
- Errors :: =rgpot::EAMTablePot= throws =std::invalid_argument= when a pair
  within the cutoff, or with a tally an owned atom, has an atomic number in no
  element line.
  The other classes throw nothing.

=rgpot::LJPot= sets =tally->energy= to NaN when two listed atoms coincide.

*** =.setHeldSkin=

#+attr_rgpot: signature
#+begin_src cpp

#+end_src

- Applies to :: rgpot::TersoffSiC, rgpot::fortranpots::TersoffPot
- Inputs :: =skin=, the extra search distance of a Verlet list kept across force

- Units :: Angstrom.

*** =.setNeighbours=

#+attr_rgpot: signature
#+begin_src cpp
void setNeighbours(std::shared_ptr<DualList> lists);
#+end_src

- Applies to :: rgpot::lr::CoulombPot, rgpot::lr::DispersionPot,
  rgpot::lr::NlhPot
- Inputs :: =lists=, a pair list with a short and a long cutoff.
- Units :: none.
- Outputs :: replaces the list the instance built in its constructor.

periodicity.

*** =.energyAndGradient=

#+attr_rgpot: signature
#+begin_src cpp
void energyAndGradient(const double *positions, const int *atomic_numbers,
                       const double *box, std::size_t n_atoms, double *energy,
                       double *gradient,
                       nlist::NeighborList *neighbors = nullptr) const;
#+end_src

- Applies to :: rgpot::StillingerWeberSi, rgpot::TersoffSiC
- Inputs :: =positions= (3 * n_atoms doubles, row-major), =atomic_numbers=
  (n_atoms entries), =box= (nine doubles, periodic in every direction), =n_atoms=,
  and an optional Verlet list =neighbors=.
- Units :: positions and box in Angstrom; energy in eV; gradient in eV/Angstrom.
- Outputs :: =*energy= and =gradient= (3 * n_atoms doubles), the derivative
  dE/dx.
  The force is the negative of the gradient.
  A null =neighbors= rebuilds the pairs on every call; a list is reused while
  each atom has moved by at most half its skin and the cell is unchanged.
- Errors :: throws
  =std::invalid_argument= for a null =energy=, or for a null =positions=, =box= or =gradient= when =n_atoms=
  > 0.

=rgpot::StillingerWeberSi= does not read
=atomic_numbers= and also throws =std::invalid_argument= for a non-finite
position.
=rgpot::TersoffSiC= also throws
=std::invalid_argument= for a null =atomic_numbers= and for an atomic number

*** =rgpot::SuttonChenPot::setPairTermLimit=

#+attr_rgpot: signature
#+begin_src cpp
void setPairTermLimit(std::size_t pairs) noexcept;
#+end_src

- Inputs :: =pairs=, the most pairs, summed over the threads of a call, whose
  density-pass terms the force pass reads back.
- Units :: none.
- Outputs :: none.
  On the three-phase stored path, this limit must satisfy
  =total_up <= pairs= or that path is skipped and the call falls back to the
  threaded two-pass row walk.
  The three-phase scratch cost from the code's per-slot vectors is 69 bytes per
  candidate upper pair:
  =active= 1 byte + =pair_phi= 8 + =pair_force= 48 + =up_j= 4 + =lo_refs= 8.

  same bits.
  The room for a call follows the pairs the previous call saw, so a walk whose
  pair count is not known in advance keeps its terms from the second call on.
  The default keeps 32 MiB of terms, and 0 keeps none.
- Errors :: none.

ExprPot(std::string expression, std::vector<Term> terms);
#+end_src

- Inputs :: =expression=, a Lepton expression over the term names; =terms=,
  pairs of a name and a =std::unique_ptr<PotentialBase>= child.
- Units :: each name stands for its child's energy in eV.
  The energy is the value of the expression, and the forces are the sum of each
  child's forces times the derivative of the expression with respect to that
  child's energy.
- Outputs :: a potential whose energy is f(E_0, E_1, ...) over the children.
  The expression and each derivative are compiled once in the constructor.
  The variance is the sum of each child's variance times its derivative, or 0
  when any child variance is not finite.
  =caps()= is the least reentrant of the children, periodic only when every
  child is.
  The force call does not write a stress.
- Errors :: the constructor throws =std::invalid_argument= for an empty
  expression, zero terms, a name that is not a Lepton identifier, a duplicate
  name, a null child, a parse, compile or differentiation failure, a term name
  the expression does not use, and an identifier in the expression that is not a
  term name.

This class is built with =-Dwith_expr=true=.

#+end_src

- Inputs :: =name=, a term name.
- Units :: none; the derivative of eV by eV.
- Outputs :: the derivative of the expression with respect to that term,

*** Term names and constructor failures

How to compose terms is in
[[file:../howto/exprpot.org][Compose potentials with ExprPot]].

A term name must be a Lepton identifier: an ASCII letter or underscore first,
then ASCII letters, digits, or underscores.
=lj=, =morse=, and =d3= are valid.
=1lj=, =lj-x=, and =lj.x= are not.

The constructor throws =std::invalid_argument= before any force call when:

- the expression is empty or blank
- there are zero terms
- a name is not a Lepton identifier
- a name is duplicated
- a child pointer is null
- Lepton cannot parse or compile the expression
- a supplied name is missing from the expression
- an identifier in the expression has no child
- =ParsedExpression::differentiate(name)= fails

Python raises =ValueError= with the same message.

** Long-range summands

These classes are in namespace =rgpot::lr= and are built with
=-Dwith_long_range=true=.
Each one owns a =DualList=, a pair list with a short and a long cutoff, until
=setNeighbours= replaces it.

*** =rgpot::lr::CoulombPot=

#+attr_rgpot: signature
#+begin_src cpp
CoulombPot(CoulombConfig cfg, std::shared_ptr<ChargeSource> charges,
           std::shared_ptr<ChargeResponse> response = nullptr);
#+end_src

- Inputs :: a =rgpot::lr::CoulombConfig=; =charges= gives the per-atom charges
  and the net charge each call; =response=, when not null, adds the chain rule
  for charges that depend on positions.
- Units :: charges in elementary charges; energy in eV, forces in
  eV/Angstrom, stress in eV/Angstrom^3.
- Outputs :: electrostatics: Ewald with a conducting boundary, smooth
  particle-mesh Ewald, or the damped shifted force in the gas phase.
  =DSF= always runs without a cell and writes no stress.
  With =Ewald= or =SPME= the force call writes the stress when the cell volume
  is positive.
- Errors :: the constructor throws =std::invalid_argument= for a null =charges=.
  The force call throws =std::invalid_argument= in the cases of
  =rgpot::lr::CoulombConfig=, when a charge, the net charge or a position is not
  finite, and when the charges do not sum to the net charge within 1e-6 (1 +
  =|net charge|=).
  =FixedCharges= throws =std::invalid_argument= when its length does not match
  the atom count.

*** =rgpot::lr::DispersionPot=

#+attr_rgpot: signature
#+begin_src cpp

                       std::shared_ptr<RatioResponse> response = nullptr);
#+end_src

- Inputs :: a =rgpot::lr::DispersionConfig=; =ratios= gives the Hirshfeld volume
  ratio and the C6 ratio per atom, and null uses ratio 1 for every atom;
  =response=, when not null, adds the chain rule for ratios that depend on

- Units :: energy in eV, forces in eV/Angstrom, stress in eV/Angstrom^3.

  the library reports an error, when the MBD screening matrix is singular and
  when an MBD eigenvalue is negative.
  =FixedRatios= throws =std::invalid_argument= when a ratio vector does not
  match the atom count.

** Fortran kernels

These classes are in namespace =rgpot::fortranpots= and are built with
=-Dwith_fortran_pots=enabled=.
Each has only a default constructor.
Each instance owns a Fortran workspace with its own neighbour table, kept
between calls.
A kernel failure throws =std::runtime_error= with the label of the kernel, the
status and the kernel's message.
A workspace that cannot be allocated throws =std::bad_alloc= from the
constructor.
Zero atoms give zero energy and forces.
Energy is eV and forces are eV/Angstrom.
The porting rules are on
[[file:fortran_potentials.org][Fortran potentials: porting rules]].

*** =rgpot::fortranpots::CuH2Pot=

- Inputs :: none.
- Units :: energy in eV, forces in eV/Angstrom.
- Outputs :: the EAM potential for copper (29) and hydrogen (1) from eOn, with a
  cutoff of 6.1 Angstrom.
  The force call does not write a stress.
- Errors :: =std::runtime_error= for an atomic number other than 29 or 1, and
  when two atoms occupy the same position.

The form is the embedded-atom method of Daw and Baskes, Physical Review B 29,
6443 (1984), doi:10.1103/PhysRevB.29.6443.
The parameters are the eOn set; this tree has no separate paper for that fit.
CuH2PotTest requires -2.7114096242662238 eV within 1e-6 for its four-atom cell.

*** =rgpot::fortranpots::EAMAlPot=

- Inputs :: none.
- Units :: energy in eV, forces in eV/Angstrom.
- Outputs :: the double-exponential EAM for aluminium from eOn, with a cutoff of
  7.1 Angstrom stored as a single-precision literal.
  Atomic numbers are not read.
  The force call does not write a stress.
- Errors :: =std::runtime_error= when the kernel or the neighbour table reports
  a failure.

The form is Daw and Baskes, Physical Review B 29, 6443 (1984),
doi:10.1103/PhysRevB.29.6443.
The parameters are the eOn set.
The four-atom =al_fcc= cluster in a 20 Angstrom cube is pinned to the EON r2549
energy -5.217864006173226 eV within 1e-12.

*** =rgpot::fortranpots::EDIPPot=

- Inputs :: none.
- Units :: energy in eV, forces in eV/Angstrom.
- Outputs :: the environment-dependent interatomic potential for silicon, with a
  cutoff of 3.1213820 Angstrom.
  Atomic numbers are not read.
  The force call does not write a stress.
- Errors :: =std::runtime_error= when the cell is thinner than the cutoff, and
  when the neighbour table reports a failure.

The potential is Bazant, Kaxiras and Justo, Physical Review B 56, 8542-8552
(1997), doi:10.1103/PhysRevB.56.8542.
Eight silicon atoms in a 20 Angstrom cube give -18.838135 eV within a relative
1e-4.

*** =rgpot::fortranpots::FeHePot=

- Inputs :: none.
- Units :: energy in eV, forces in eV/Angstrom.
- Outputs :: the iron (26) and helium (2) potential from eOn, with Fe-Fe, Fe-He
  and He-He pair terms.
  The neighbour table uses the largest of its cutoffs, 5.4 Angstrom for the
  He-He pair.
  The force call does not write a stress.
- Errors :: =std::runtime_error= for an atomic number other than 26 or 2.

The iron part is Ackland and coauthors, Journal of Physics: Condensed Matter 16,
S2629-S2642 (2004), doi:10.1088/0953-8984/16/27/003.
A pure helium configuration reduces to the HFD-B dimer of Aziz, McCourt and
Wong, Molecular Physics 61, 1487-1511 (1987), doi:10.1080/00268978700101941.
Sixteen iron atoms in a 20 Angstrom cube give -43.959774 eV within a relative
1e-4.

- Inputs :: none.

*** =rgpot::fortranpots::SWPot=

- Inputs :: none.

- Outputs :: Stillinger-Weber silicon with eOn's epsilon, 2.16826 * 1.06767385

*** =rgpot::fortranpots::WaterHPot=

- Inputs :: none.
- Units :: energy in eV, forces in eV/Angstrom.
- Outputs :: one hydrogen atom in the field of water molecules, Andersson's
  potH-H2O surface.
  Atoms are hydrogen (1) and oxygen (8): whole water molecules followed by the
  lone H as the last atom.
  Every site interacts with the lone H at its nearest periodic image; there is
  no cutoff.
  The force call does not write a stress.
- Errors :: =std::runtime_error= for fewer than 4 atoms, for an atomic number

  lone H.

The surface is Andersson, Al-Halabi, Kroes and van Dishoeck, Journal of Chemical
Physics 124, 064715 (2006), doi:10.1063/1.2162901.
No test in this tree pins an absolute energy for this class.

* Engine plugin ABI

=CppCore/rgpot/engine_c_abi.h= declares the functions a host calls to drive an
engine shared library through =dlopen= and =dlsym=.
The host selects the backend by the library it opens.
The configuration is a Cap'n Proto flat-array message whose root is the engine's
params struct in =Potentials.capnp=.
Positions and cells are in Angstrom, energies in eV and forces in eV/Angstrom.
A cell is nine doubles in row-major order.

Status codes are three-valued. 0 is success.
A positive value means the evaluation failed at this input and the caller may
back off.
A negative value means the instance is unusable.
The engines in this repository return 1 for an invalid argument, 2 when the
evaluation or the setting failed (the reason is in =rgpot_engine_last_error=),
and 3 when the backend does not support the operation.
=rgpot_engine_force= and =rgpot_engine_force_batch= also return the nonzero code
of the host's coordinate transform.

To open, build and test an engine, see
[[file:../howto/engine-plugins.org][Open, build and test engine plugins]].

** Libraries

=CppCore/rgpot/engine/EngineTable.cc= implements every function the engine
libraries export except =rgpot_engine_abi_stamp=, for any =PotentialBase=.
=CppCore/rgpot/engine/EngineAbiStamp.cc= defines =rgpot_engine_abi_stamp=.
Every engine plugin, including the standalone ones that do not use the table,
adds that file, so all of them report the same ABI major, minor and layout
revision.
Each library adds one file that defines =rgpot::engine::create= (build the
potential from the params message) and =rgpot::engine::backend_name=.

| library | root message | backend name | selects |
|---------+--------------+--------------+---------|
| =libuma_engine= | =UmaParams= | =uma= | the UMA package at =modelPath= |
| =libmetatomic_engine= | =MetatomicParams= | =metatomic= | the metatomic model at =modelPath= |
| =libxtb_engine= | =BuiltinParams= | =xtb= | GFN2-xTB with the =XTBConfig= defaults; =name= is empty or =xtb= |
| =libclassical_engine= | =BuiltinParams= | =classical= | =name= =lj=, =ljcluster=, =morse=, =zbl=, =eckart=, =muller_brown=, =modified_muller_brown=, =leps_hh2=, =leps_hcl2=, =leps_fh2=, =double_well=, =coupled_proton_well= and (when built with CBE) =cbe=; with the water kernels =tip4p=, =spce=, =tip4p_pt=; with the Fortran kernels =sw=, =edip=, =lenosky=, =tersoff=, =eamal=, =fehe=, =cuh2=, =waterh=; all with default parameters |
| =libcomposite_engine= | =CompositeParams= | =composite= | a weighted sum: each =CompositeTerm= names its child with a =PotentialSpec=, the =builtin= arm for =lj=, =morse=, =zbl=, =d2= and a nested =composite= (with their config arms) or the =cpmd= arm; a disabled term is not built |
| =libmopac_engine= | =BuiltinParams= | =mopac= | MOPAC; =name= is empty or =mopac=, =library= is the path of =libmopacc= |
| =libnwchem_engine= | =NWChemParams= | =nwchem= | NWChem through =libnwchemc= |
| =libskala_engine= | =NWChemParams= | =skala= | Skala XC on NWChem; reads =basis=, =charge=, =multiplicity=, =enginePath= and =nwchemRoot= |

=BuiltinParams.name= is compared in lower case.
The Metatomic and XTB libraries also export their own tables
(=rgpot_mta_*=, =rgpot_xtb_*=).
NWChem and CPMD keep the prefix-parameterized profile ABI that =NWChemPot= and
=CPMDPot= load, and MOPAC keeps =mopac_c_abi.h=.
The plugin interface in =include/rgpot/plugin.h= is a separate family. tblite,
dftd3, dftd4, ExprPot, XcKernel, CPMD and CP2K have no engine library.

Every library above exports
=rgpot_engine_force_batch=, =rgpot_engine_hvp=, =rgpot_engine_abi_stamp=,
=rgpot_engine_abi_compatible=, =rgpot_engine_name=, =rgpot_engine_version=, =rgpot_engine_model_digest=,
=rgpot_engine_caps=,
=rgpot_engine_last_error=, =rgpot_engine_set_num_threads=, =rgpot_engine_set_charge_spin=, =rgpot_engine_select_orbitals=,
=rgpot_engine_copy_orbitals=, =rgpot_engine_last_components= and
=rgpot_engine_component_name=.
Only =libcomposite_engine= has components; the others report none.
None of them exports =rgpot_engine_model_state=, =rgpot_engine_set_callbacks=,
=rgpot_engine_hint= or =rgpot_engine_neighbor_options=.

*** =RgpotEngineAbiStamp=

- Inputs :: none; a value type.
- Units :: none.
- Outputs :: three =unsigned short= fields:
  =abi_major= (=RGPOT_ENGINE_ABI_VERSION=, 1),
  =abi_minor= (=RGPOT_ENGINE_ABI_MINOR=, 5) and
  =layout_revision= (=RGPOT_ENGINE_ABI_LAYOUT_REVISION=, 1).
- Errors :: none.

The major increments for an incompatible change.
The minor increments for an addition that leaves every existing call valid: a
new optional symbol, or a new field at the end of a size-prefixed structure.
The layout revision increments when an existing structure changes size or field
order.
A host built against minor N runs against an engine of the same major and layout
revision whose minor is at least N. An engine without =rgpot_engine_abi_stamp=
is minor 0, layout 1.
Minor 1 added the stamp, =rgpot_engine_caps=,
=rgpot_engine_last_error=, =rgpot_engine_set_num_threads= and =rgpot_engine_set_charge_spin=.
Minor 2 added =rgpot_engine_name=, =rgpot_engine_version=,
=rgpot_engine_model_digest= and the generic table for every backend.
Minor 3 added
=RgpotEngineCaps.orbital_selection=, =RgpotEngineCaps.orbital_copy=,
=rgpot_engine_select_orbitals= and =rgpot_engine_copy_orbitals=.
Minor 4 added =rgpot_engine_hvp= and the trailing =RgpotEngineCaps.analytic_hvp=
field.
Minor 5 added =RgpotEngineComponent=,
=rgpot_engine_last_components= and =rgpot_engine_component_name=.
The version does not cover the Cap'n Proto params schema, the tensor runtime the
engine links, or the model.

** Instances

*** =RgpotEnginePot=

- Inputs :: none; an opaque handle.
- Units :: none.
- Outputs :: returned by =rgpot_engine_create= and released by
  =rgpot_engine_destroy=.
- Errors :: none.

A handle holds the backend potential, its capabilities, the last error message
and the model digest once computed.

*** =rgpot_engine_create=

#+attr_rgpot: signature
#+begin_src c
RgpotEnginePot *rgpot_engine_create(const void *config, size_t config_len,
                                    char *errbuf, size_t errlen);
#+end_src

- Inputs :: =config=, a Cap'n Proto flat-array message (as produced by
  =capnp::messageToFlatArray=) whose root is the library's params struct;
  =config_len=, its length in bytes; =errbuf= and =errlen=, a buffer for the
  failure reason (may be null or 0).
- Units :: none.
- Outputs :: a new handle, or NULL on failure.
- Errors :: returns NULL and writes the reason to =errbuf= (at most =errlen - 1=
  bytes, NUL-terminated).
  A null =config=, a zero
  =config_len= or a length that is not a multiple of 8 gives =rgpot_engine_create(<name>): a word-aligned Cap'n Proto params message is required=.
  An empty =modelPath= (UMA, Metatomic), an unknown =BuiltinParams.name=, a
  malformed message or an exception from the backend constructor gives that
  message.
  A =MetatomicParams.charge= or =spin= the model does not read, other than
  charge 0 or multiplicity 1, gives =rgpot_engine_create(metatomic):= followed
  by the reason =rgpot_engine_set_charge_spin= gives.

Required symbol.
=UmaParams= and =MetatomicParams= carry =intraopThreads= and =interopThreads=
(default 1), which create applies with the rules of
=rgpot_engine_set_num_threads=; a refused inter-op count fails create with the
reason.
=UmaParams.deterministicAlgorithms= turns on deterministic torch algorithms, so
an operation without a deterministic implementation throws.
=MetatomicParams.torchDeterminism= (=fast= or =deterministic=) selects the
=TorchDeterminismPolicy= of the Metatomic potential.
=MetatomicParams.charge=, =spin= (a value below 1 becomes 1) and
=attachSystemExtras= go to the Metatomic potential; see Charge and spin below.
=UmaParams.cacheDir= is the root of the cache the UMA package is unpacked into;
see the UMA unpack cache below.

*** =rgpot_engine_destroy=

#+attr_rgpot: signature
#+begin_src c
void rgpot_engine_destroy(RgpotEnginePot *pot);
#+end_src

- Inputs :: =pot=, a handle from =rgpot_engine_create= or NULL.
- Units :: none.
- Outputs :: none; the handle and its backend are freed.
- Errors :: none; NULL is accepted.

Required symbol.
Must not run concurrently with another call on the same handle.

*** =RgpotEngineCaps=

- Inputs :: =size=, set by the host to =sizeof(RgpotEngineCaps)= before
  =rgpot_engine_caps=.
- Units :: none.
- Outputs :: =size= (bytes the engine wrote), =reentrancy=,
  =per_image_instances=, =batched=, =periodic=, =stress=,
  =group_collective=, =orbital_selection=, =orbital_copy= and =analytic_hvp=;
  the flags are 0 or 1.
- Errors :: none.

The fields mirror rgpot's =PotCaps=.
=per_image_instances= asks multi-image methods (NEB) to clone one instance per
image.
=batched= means the backend serves =rgpot_engine_force_batch= natively.
=periodic= means periodic boundary conditions are supported.
=stress= means the backend computes cell stress; the engine ABI has no call that
returns it.
=group_collective= means every rank of a calculator group enters each call.
=orbital_selection= means the backend supports =rgpot_engine_select_orbitals=.
=orbital_copy= means the backend supports =rgpot_engine_copy_orbitals=.
=analytic_hvp= means =rgpot_engine_hvp= returns an exact directional product.

=reentrancy= decides how the table admits concurrent =rgpot_engine_force= and
=rgpot_engine_force_batch= calls:

- 0, shared instance: calls run concurrently on one handle (UMA, Metatomic).
- 1, per instance: one call at a time per handle; calls on different handles run
  concurrently (XTB and every potential of the classical engine).
- 2, process serial: one call at a time across all handles of the library in the
  process (MOPAC, NWChem, Skala).

*** =rgpot_engine_caps=

#+attr_rgpot: signature
#+begin_src c
int rgpot_engine_caps(const RgpotEnginePot *pot, RgpotEngineCaps *out);
#+end_src

- Inputs :: =pot=, a handle; =out=, a structure whose =size= field the host has
  set.
- Units :: none.
- Outputs :: 0 on success; the engine copies at most =out->size= bytes of its
  structure into =out= and sets =out->size= to the number of bytes written.
- Errors :: returns 1 when =pot= or =out= is null, or when =out->size= is
  smaller than an =unsigned=; =out= is then not written and
  =rgpot_engine_last_error= is not set.

Optional symbol.

*** =rgpot_engine_last_error=

#+attr_rgpot: signature
#+begin_src c
size_t rgpot_engine_last_error(const RgpotEnginePot *pot, char *buf, size_t len);
#+end_src

- Inputs :: =pot=, a handle; =buf= and =len=, the destination (may be null or 0
  to query the length).
- Units :: none.
- Outputs :: the full length of the message of the last failed call on the
  handle, 0 when there is none; at most =len - 1= bytes are copied to =buf= and
  NUL-terminated.
- Errors :: a null =pot= returns 0 and writes nothing.

Optional symbol.
Reading does not clear the message.
A successful =rgpot_engine_force=,
=rgpot_engine_force_batch=, =rgpot_engine_hvp=, =rgpot_engine_set_num_threads=, =rgpot_engine_set_charge_spin=, =rgpot_engine_select_orbitals=
or =rgpot_engine_copy_orbitals= clears it.
Errors of =rgpot_engine_create= go to its =errbuf=.
May run at any time, also during an evaluation on the same handle.

*** =rgpot_engine_model_digest=

#+attr_rgpot: signature
#+begin_src c
size_t rgpot_engine_model_digest(const RgpotEnginePot *pot, char *buf, size_t len);
#+end_src

- Inputs :: =pot=, a handle; =buf= and =len=, the destination.
- Units :: none.
- Outputs :: 64, with the SHA-256 of the model file as 64 lowercase hexadecimal
  digits copied to =buf= (at most =len - 1= bytes, NUL-terminated); 0 when the
  backend has no model file.
- Errors :: returns 0 and writes an empty string when =pot= is null, the backend
  has no model file (every library except UMA and Metatomic), or the file cannot
  be read.

Optional symbol.
The digest is computed on the first request and kept for the life of the handle,
including a failed read.
For =libuma_engine= it is the digest of the =.pt2=; the digest of the weights
inside it is package metadata, under UMA checkpoint provenance below.
May run at any time.

*** =rgpot_engine_set_num_threads=

#+attr_rgpot: signature
#+begin_src c
int rgpot_engine_set_num_threads(RgpotEnginePot *pot, int intra_op, int inter_op);
#+end_src

- Inputs :: =pot=, a handle; =intra_op= and =inter_op=, the intra-op and
  inter-op worker thread counts of the engine's tensor runtime (a value below 1
  leaves that count alone).
- Units :: none.
- Outputs :: 0 on success.
- Errors :: returns 1 for a null =pot= (no message).
  Returns 3 for a backend without a tensor runtime (every library except UMA and
  Metatomic), with =backend has no tensor runtime= in =rgpot_engine_last_error=.
  Returns 2 when the runtime refuses the setting, with the reason in
  =rgpot_engine_last_error=.

Optional symbol.
The counts act on the process's libtorch, so engines in one process share them.
The inter-op count can be set once per process before the runtime starts
parallel work; asking for the count already in force succeeds and another count
afterwards returns 2.
Must not run concurrently with another call on the same handle.

*** =rgpot_engine_set_charge_spin=

#+attr_rgpot: signature
#+begin_src c
int rgpot_engine_set_charge_spin(RgpotEnginePot *pot, int charge, int spin);
#+end_src

- Inputs :: =pot=, a handle; =charge=, the total charge; =spin=, the spin
  multiplicity (1 is a singlet).
- Units :: =charge= in elementary charges; =spin= none.
- Outputs :: 0 on success; the next evaluations use the new values.
- Errors :: returns 1 for a null =pot= or =spin= below 1 (no message).
  Returns 3 for a backend without a charge or spin, with
  =backend has no charge or spin to change= in =rgpot_engine_last_error=: the
  classical, MOPAC, NWChem and XTB libraries, and Metatomic with a model that
  reads neither.
  Returns 3 for a value the backend cannot take, with the reason in
  =rgpot_engine_last_error=; the values in force do not change.
  For Metatomic the reason is
  =the model reads no charge (rgpot::charge), so charge <n> cannot reach it= or
  the same sentence for the spin multiplicity.
  Returns 2 when the backend throws, with the reason in
  =rgpot_engine_last_error=.

Optional symbol.
UMA stores the values and passes them to the model at the next evaluation.
Skala applies them to NWChem at once.
Metatomic stores them for the next evaluations of a model that reads them; see
Charge and spin below.
Must not run concurrently with another call on the same handle.

*** =rgpot_engine_select_orbitals=

#+attr_rgpot: signature
#+begin_src c
int rgpot_engine_select_orbitals(RgpotEnginePot *pot, long long key);
#+end_src

- Inputs :: =pot=, a handle; =key=, the orbital slot identifier.
- Units :: none.
- Outputs :: 0 on success.
  On CPMD backends, seeding a key means choosing the next SCF initial guess from
  the session's current converged orbitals or from the orbitals last converged
  under that key.
- Errors :: returns 1 for a null =pot= (no message).
  Returns 3 when the backend has no orbital-selection primitive, with
  =backend has no orbital selection= in =rgpot_engine_last_error=.
  Returns 3 when the backend rejects =key= and reports it through an
  =Unsupported= exception, with the reason in =rgpot_engine_last_error=.
  Returns 2 for another backend exception, with the reason in
  =rgpot_engine_last_error=.

Optional symbol.

*** =RgpotEngineComponent=

- Inputs :: none; a value type filled by =rgpot_engine_last_components=.
- Units :: =energy= eV and =stress= eV/Angstrom^3 row-major, the term's own
  values before its =weight=.
- Outputs :: =double weight=, =double energy=, =double stress[9]=, =int enabled=
  (0 for a term switched off), =int evaluated= (0 for a disabled term and before
  the first call) and =int has_stress=.
- Errors :: none.

*** =rgpot_engine_last_components=

#+attr_rgpot: signature
#+begin_src c
long rgpot_engine_last_components(const RgpotEnginePot *pot,
                                  RgpotEngineComponent *out, double *forces,
                                  long capacity);
#+end_src

- Inputs :: =pot=, a handle; =out=, room for =capacity= records (may be null
  with =capacity= 0 to query the count); =forces=, null or room for =capacity=
  blocks of =3 * nAtoms= doubles, =nAtoms= of the last successful call.
- Units :: =forces= in eV/Angstrom, each term's own forces before its weight.
- Outputs :: the number of terms of a composite engine, whatever =capacity=; the
  first =capacity= records are written in term order from the last successful
  =rgpot_engine_force= on the handle, or the last system of the last
  =rgpot_engine_force_batch=.
  The force blocks are term-major and zero for a term that was not evaluated.
  An engine that is not a sum returns 0 and writes nothing.
- Errors :: returns -1 for a null =pot=.

Optional symbol, minor 5.
The record of a failed call is that of the terms that ran before the failure.
The call takes the handle's call lock, so it waits for an evaluation on the same
handle to finish.

** Evaluation

*** =rgpot_engine_coord_transform=

#+attr_rgpot: signature
#+begin_src c
typedef int (*rgpot_engine_coord_transform)(void *user, long nAtoms,
                                            double *positions, double *box);
#+end_src

- Inputs :: =user=, the =transform_user= pointer of the force call; =nAtoms=;
  =positions=, 3*nAtoms doubles; =box=, 9 doubles, row-major.
- Units :: =positions= and =box= in Angstrom.
- Outputs :: 0 on success; the transform edits =positions= and =box= in place.
- Errors :: a nonzero return aborts the force call, which returns the same code.

The engine applies the transform to its own scratch copy, so the caller's
buffers are not changed.
An example is a molecular-box convention that recentres a gas-phase molecule in
a fixed cell.

*** =rgpot_engine_force=

#+attr_rgpot: signature
#+begin_src c
int rgpot_engine_force(RgpotEnginePot *pot, long nAtoms, const double *positions,
                       const int *atomicNrs, double *forces, double *energy,
                       double *variance, const double *box,
                       rgpot_engine_coord_transform transform,
                       void *transform_user);
#+end_src

- Inputs :: =pot=, a handle; =nAtoms=, the atom count; =positions=, 3*nAtoms
  doubles, row-major (x, y, z per atom); =atomicNrs=, nAtoms atomic numbers;
  =box=, 9 doubles, row-major; =transform= and =transform_user=, an optional
  coordinate transform (may be NULL).
- Units :: =positions= and =box= in Angstrom; energy in eV; forces in
  eV/Angstrom.
- Outputs :: 0 on success; =forces=,
  3*nAtoms doubles in the layout of =positions=; =*energy=; =*variance=, the
  backend's uncertainty estimate without unit conversion (0 for backends that
  have none; =variance= may be NULL).
- Errors :: returns 1 when =pot=, =positions=, =atomicNrs=, =forces=, =energy=
  or =box= is null or =nAtoms= is not positive, with =invalid argument= in
  =rgpot_engine_last_error=.
  Returns the transform's nonzero code with
  =coordinate transform returned <code>=.
  Returns 2 when the backend throws, with the exception text in
  =rgpot_engine_last_error= and on standard error as =rgpot_engine(<name>): <text>=.
  On failure =forces=, =*energy= and =*variance= are not written.

Required symbol.
Any thread may call it on any handle; concurrency follows
=RgpotEngineCaps.reentrancy=.
When the host holds the Python GIL, the call releases it during the evaluation.

*** =rgpot_engine_force_batch=

#+attr_rgpot: signature
#+begin_src c
int rgpot_engine_force_batch(RgpotEnginePot *pot, long nSystems, long nAtoms,
                             const double *positions, const int *atomicNrs,
                             double *forces, double *energies, double *variances,
                             const double *boxes,
                             rgpot_engine_coord_transform transform,
                             void *transform_user);
#+end_src

- Inputs :: =pot=, a handle; =nSystems= systems of one composition (=nAtoms=,
  =atomicNrs= with nAtoms entries); =positions=, 3*nAtoms*nSystems doubles with
  system stride 3*nAtoms; =boxes=, 9*nSystems doubles with system stride 9;
  =transform= and =transform_user=, applied per system (may be NULL).
- Units :: as =rgpot_engine_force=.
- Outputs :: 0 on success; =forces=, 3*nAtoms*nSystems doubles in the layout of
  =positions=; =energies=, nSystems doubles; =variances=, nSystems doubles (may
  be NULL).
- Errors :: returns 1 when a required pointer is null or =nSystems= or =nAtoms=
  is not positive, with =invalid argument (batch)= in =rgpot_engine_last_error=.
  Returns the first nonzero transform code; no system is evaluated.
  Returns 2 when the backend throws, with the reason as for
  =rgpot_engine_force=.
  The backend writes =forces= in place, so after a code 2 =forces= may be partly
  written; =energies= and =variances= are not written.

*** =rgpot_engine_hvp=

#+attr_rgpot: signature
#+begin_src c
int rgpot_engine_hvp(RgpotEnginePot *pot, long nAtoms,
                     const double *positions, const int *atomicNrs,
                     const double *direction, double *hv_out,
                     const double *box);
#+end_src

- Inputs :: the potential and geometry as for =rgpot_engine_force=, plus
  =direction= with =3 * nAtoms= Cartesian entries; =direction= and =hv_out= must
  not overlap.
- Units :: positions, box and direction in Angstrom; =hv_out= is the energy
  Hessian (eV/Angstrom squared) times that direction, hence eV/Angstrom.
- Outputs :: =RGPOT_ENGINE_OK= and the exact energy-Hessian product in =hv_out=.
- Errors :: returns
  =RGPOT_ENGINE_ERR_INVALID= for a NULL pointer, an invalid atom count, or overlapping =direction= and =hv_out=;
  =RGPOT_ENGINE_ERR_UNSUPPORTED= when the potential does not advertise =analytic_hvp=;
  and =RGPOT_ENGINE_ERR_EVAL= when the implementation throws.
  The reason is available from =rgpot_engine_last_error=.

Optional symbol.
Absence of the symbol or a false =analytic_hvp= is a hard unsupported result;
the adapter and Rust loader never approximate it with finite differences.
For learning engines the call is also an incorporation boundary.
A variant for groups of different compositions would be a separate symbol.

** Learning engines

No engine in this repository implements this set; the entries state what the
header requires.

*** =RgpotEngineGprGate=

- Inputs :: =magic= (=RGPOT_ENGINE_GPR_GATE_MAGIC=, =0x47505247=), =version=
  (=RGPOT_ENGINE_GPR_GATE_VERSION=, 1), =sigmaLoFactor=, =sigmaHiFactor=,
  =certifyBelowForce=, =refitTrainingRevisions=.
- Units :: =sigmaLoFactor= and =sigmaHiFactor= are multiples of the model's
  likelihood noise (none); =certifyBelowForce= in eV/Angstrom;
  =refitTrainingRevisions= is a count.
- Outputs :: passed as the =config= blob of =rgpot_engine_create= to a learning
  engine.
- Errors :: none in the header; an engine dispatches on =magic=.

The model answers below =sigmaLoFactor= times its noise.
Above =sigmaHiFactor= times its noise the geometry is not learned from.
A predicted force magnitude below =certifyBelowForce= forces a ground-truth
call; a non-positive value disables this check.
=refitTrainingRevisions= is the refit cadence in training-set appends; 0 refits
at every incorporation boundary.
The header marks the structure as interim, to be replaced by a Cap'n Proto
=GprParams= arm.

** Charge and spin

=rgpot_engine_set_charge_spin= sets the total charge and the spin multiplicity
of the next calls on a handle, and a multiplicity below 1 returns 1.
A value the backend cannot take returns 3, keeps the values in force and leaves
the reason in =rgpot_engine_last_error=.
No engine returns 0 for a value its model does not receive.

| library | charge and multiplicity |
|---------+-------------------------|
| =libuma_engine= | graph inputs of every call; =UmaParams.charge= and =spin= at create |
| =libmetatomic_engine= | system data the model declares; =MetatomicParams.charge= and =spin= at create |
| =libskala_engine= | the NWChem input of the next call; =NWChemParams.charge= and =multiplicity= at create |
| =libclassical_engine=, =libmopac_engine=, =libnwchem_engine=, =libxtb_engine= | none, so 3 for any value |

A UMA package records the charge and spin it was exported for, and the next
force call reports a mismatch.
A Metatomic model reads the charge as =rgpot::charge= and the multiplicity as
=rgpot::spin_multiplicity= or =rgpot::spin=.
Each system carries the names the model declares in =requested_inputs=.
Without =attachSystemExtras=, a model that declares none of them gets 3 from
=rgpot_engine_set_charge_spin=.
A value the model does not read must stay at its default, charge 0 or
multiplicity 1.
=rgpot_engine_set_charge_spin= returns 3 for another, and =create= fails for one
in =MetatomicParams=.
=MetatomicParams.attachSystemExtras= attaches all three names and accepts any
value, for a model that reads them without declaring them.
It needs =checkConsistency= off, because metatomic then rejects data the model
does not declare.
[[file:../howto/engine-metatomic.org][Metatomic and the engine ABI]] shows the
declaration.

** UMA unpack cache

=UmaParams.cacheDir= (=UmaConfig::cache_dir= for a directly compiled =UmaPot=)
names the root of the persistent cache that the =.pt2= is unpacked into.
When it is empty the root is =$RGPOT_CACHE_DIR=, then =$XDG_CACHE_HOME/rgpot=
(absolute values only), then =.rgpot-cache= in the working directory. torch's
=AOTIModelPackageLoader= is not used, because it unpacks into a new directory
under the system temporary directory and leaves it behind when the process dies.

| Path under the root                         | Contents                                             |
|---------------------------------------------+------------------------------------------------------|
| =aoti/<sha256>.model/=                      | the package's =data/aotinductor/model= files and constants, as torch lays them out |
| =aoti/<sha256>.model/rgpot-unpack.manifest= | package digest, model name, and the size of every unpacked file |
| =aoti/.<sha256>.model.tmp-*=                | an unpack in progress                                |

=<sha256>= is the digest of the =.pt2= bytes, so two models never share a
directory and a rewritten package gets a new one.
An unpack is written into a private =.tmp-= sibling and renamed into place once
its manifest is complete.
Processes and threads that load the same package at once each build a sibling,
one rename wins, and the others use the winner's directory.
A directory whose manifest is missing or whose files have the wrong size is
replaced.
Shared libraries lose the executable-stack flag (=PT_GNU_STACK= =PF_X=) on the
way, for loaders that refuse an executable stack.
A =.tmp-= sibling older than an hour, left by a process that died, is removed
the next time that package is loaded.

** UMA checkpoint provenance

=rgpot_engine_model_digest= of =libuma_engine= is the SHA-256 of the =.pt2=.
The digest of the weights inside it is package metadata, written by
=scripts/export_uma_aoti.py=:

| Key                      | Value                                                          |
|--------------------------+----------------------------------------------------------------|
| =checkpoint_source=      | =cli=, =env= or =hf=: where the exporter took the checkpoint from |
| =checkpoint_path=        | the local checkpoint file (=cli= and =env=)                    |
| =checkpoint_hf_repo=     | Hugging Face repository (=hf=)                                 |
| =checkpoint_hf_filename= | file inside that repository (=hf=)                             |
| =checkpoint_hf_revision= | commit the file was served from (=hf=)                         |
| =checkpoint_sha256=      | SHA-256 of the checkpoint file, 64 lowercase hexadecimal digits |

=UmaPot::checkpointProvenance()= returns them as a =UmaCheckpointProvenance=,
whose fields are =std::optional= and unset for packages exported before the keys
existed.
=UmaPot= prints =checkpoint_sha256= on stderr when it loads the package, and
=unset= for those packages.
No engine ABI call returns the keys.
A malformed =checkpoint_sha256=, =checkpoint_hf_revision= or =checkpoint_source=
fails the load.

** CP2K shim

=CP2KPot= drives CP2K through
=libcp2kc_rgpot=, a shim over libcp2k declared in =CppCore/rgpot/CP2KPot/cp2kc_abi.h=
(=CP2KC_ABI_VERSION= 1).
This is a separate ABI from the engine table.
The shim is the only target that links libcp2k and MPI; =CP2KPot= opens it with
=dlopen=, so =librgpot= gains neither dependency.
Meson builds it with
=-Dwith_cp2k=enabled= from the =libcp2k= pkg-config module (CMake: =-DRGPOT_WITH_CP2K=ON=).
Without it =librgpot= contains no CP2K code, =potserv CP2K= exits with an error
naming the option, and the other potserv backends refuse the =cp2k= arm in
=configure()=.
=CP2KPot= tries =CP2KParams.enginePath=, then
=CP2KC_LIBRARY=, then =RGPOT_CP2K_ENGINE=, then =libcp2kc_rgpot.so= and
=./libcp2kc_rgpot.so= (=.dylib= on macOS).

| symbol | purpose |
|--------+---------|
| =cp2kc_abi_version=, =cp2kc_version=, =cp2kc_available= | identity |
| =cp2kc_adopt_calculator_comm= | borrow the calculator's =MPI_Comm= |
| =cp2kc_session_create= | write the deck to =dir/input.inp=, initialise libcp2k once |
| =cp2kc_session_select_orbitals= | name the key whose force environment the next call uses |
| =cp2kc_session_calculate= | positions and cell in Bohr in, Hartree and Hartree/Bohr forces out |
| =cp2kc_session_destroy= | destroy the session's force environments |

The shim uses CP2K's atomic units and takes no Cap'n Proto.
=CP2KPot= renders the deck from =CP2KParams= and the first geometry, multiplies
positions and cell rows by =ANGSTROM_TO_BOHR=, and returns the energy times
=HARTREE_TO_EV= and the forces times =HARTREE_BOHR_TO_EV_ANGSTROM=. libcp2k
returns forces, so there is no sign change.
The cell rows are the cell vectors a, b and c.

=cp2kc_session_calculate= returns 0 on success, 1 for a bad argument (including
an atom count that differs from the deck), 2 when the SCF did not converge, and
a negative value on a fatal error.
The rendered deck sets =IGNORE_CONVERGENCE_FAILURE=, so CP2K warns instead of
calling =MPI_ABORT=.
After each evaluation the first rank of the calculator reads the new part of
=cp2k.out= for =SCF run NOT converged= and shares the result, so every rank
returns 2 for the same call.
=CP2KPot= turns code 2 into =rgpot::CP2KScfError= (a =std::runtime_error=) on
every rank without the error exchange.
Any other failure takes the abort path described in [[file:mpi.org][MPI]].
=CP2KPot= sets =has_stress= to 0.

No second engine abstraction is added: =EnginePotential::into_potential= wraps
the handle as a =PotentialImpl=.

- =ENGINE_ABI_VERSION=, =ENGINE_ABI_MINOR=,
  =ENGINE_ABI_LAYOUT_REVISION= :: Host ABI identity (=1=, =5=, =1=) matching =RGPOT_ENGINE_ABI_VERSION=,
  =RGPOT_ENGINE_ABI_MINOR= and =RGPOT_ENGINE_ABI_LAYOUT_REVISION=.
- =RgpotEngineAbiStamp= :: Compatibility stamp (=abi_major=, =abi_minor=,
  =layout_revision=) with =RgpotEngineAbiStamp::HOST= and =serves(host)= implementing the =rgpot_engine_abi_compatible=
  rule.
- =RgpotEnginePot= :: Opaque handle type matching =struct RgpotEnginePot=.
- =CoordTransformFn=, =AbiVersionFn=, =AbiStampFn=, =CreateFn=, =DestroyFn=,
  =ForceFn=, =ForceBatchFn=, =HvpFn=, =CapsFn=, =LastErrorFn= :: =extern "C"=
  function-pointer types matching the C declarations above.
- =EngineSymbols= :: Resolved symbol table holding required
  (=abi_version=, =create=, =destroy=, =force=) and optional (=abi_stamp=,
  =force_batch=, =hvp=, =caps=, =last_error=) function pointers.
- =EngineError= :: Typed error enum covering =Load=, =Missing=, =Abi=
  (=expected=, =found=), =AbiStamp= (=expected=, =found=), =Create=, =Invalid=,
  =Unsupported=, =Recoverable= (=code=, =message=), and =Fatal= (=code=,
  =message=).
- =EngineRequest= :: Single-geometry input with =positions= (Angstrom, row-major
  =[n_atoms, 3]=), =atomic_numbers=, and =box_matrix= (row-major 3x3 lattice in
  Angstrom).
- =EngineEvaluation= :: Output containing =energy= (eV) and =forces=
  (eV/Angstrom, row-major =[n_atoms, 3]=).
- =EnginePotential::load(path, config)= /
  =EnginePotential::from_symbols(symbols, config)= :: Verifies =rgpot_engine_abi_version() ==
  ENGINE_ABI_VERSION=, resolves the optional
  =rgpot_engine_abi_stamp= (treating an engine without it as minor 0, layout 1) and requires =stamp.serves(RgpotEngineAbiStamp::HOST)=, copies =config= into an 8-byte-aligned =Vec<u64>= buffer (so engines that cast =config= to =capnp::word= never receive an unaligned pointer), and calls =rgpot_engine_create=.
  =EnginePotential::abi_stamp()= returns the resolved stamp.
- =EnginePotential::force(&request)= and
  =EnginePotential::force_batch(&atomic_numbers, &positions, &boxes)= ::
  Validates input lengths and output finiteness, dispatches to
  =rgpot_engine_force= or
  =rgpot_engine_force_batch=, and maps positive codes to =EngineError::Recoverable= and negative codes to =EngineError::Fatal= using =rgpot_engine_last_error=
  when present.
  A negative status poisons the handle: every later call on that
  =EnginePotential= (or the =PotentialImpl= built from it) returns the same
  =EngineError::Fatal= without calling into native code, while dropping the
  handle still calls =rgpot_engine_destroy= once to release the =RgpotEnginePot=
  allocation.
- =EnginePotential::caps()= / =EnginePotential::hvp(&request, direction)= ::
  Reads the size-prefixed engine capability structure and dispatches the exact
  product.
  A missing symbol, a false
  =analytic_hvp= bit, or =RGPOT_ENGINE_ERR_UNSUPPORTED= returns
  =EngineError::Unsupported= (retaining the engine's last-error message) without
  a finite-difference fallback.
- =EnginePotential::into_potential(self)= :: Converts the instance into a =PotentialImpl= callback handle, serializes calls to its engine instance, and registers an analytic callback on the underlying =rgpot_potential_t= only when both =rgpot_engine_caps= and =rgpot_engine_hvp= are exported and =analytic_hvp=
  is true.

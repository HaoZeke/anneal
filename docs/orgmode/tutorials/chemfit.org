===================
ChemFit Integration
===================
#+end_export

ChemFit owns parameter reconstruction, callbacks, exception penalties, and
the best evaluated parameter set. =anneal= owns the bounded proposal chain.
Keep those responsibilities separate: call =fitter.step()= exactly once after
each =fitter.evaluate()= and return =fitter.finish()= rather than rebuilding
the result from =History.best_pos=.

For a positions-only fit:

#+begin_src python
from typing import Any

import numpy as np
from anneal import Boltzmann, run


def run_anneal(benchmark_context: dict[str, Any]):
    fitter = benchmark_context["fitter"]
    budget = int(benchmark_context["budget"])
    initial = np.asarray(
        benchmark_context["initial_params"]["positions"],
        dtype=np.float64,
    )
    n_atoms = initial.shape[0]

    if initial.shape != (n_atoms, 3):
        raise ValueError("positions must have shape (n_atoms, 3)")
    if budget < 1:
        raise ValueError("budget must be positive")

    low = np.full(initial.size, -3.0)
    high = np.full(initial.size, 3.0)

    fitter.init()
    if hasattr(fitter, "evaluate"):
        evaluate = fitter.evaluate
        advance = fitter.step
    else:
        evaluate = fitter.ask
        advance = fitter.tell

    def objective(position):
        params = {"positions": np.asarray(position).reshape(n_atoms, 3)}
        loss = evaluate(params)
        advance()
        return float(loss)

    run(
        objective,
        low,
        high,
        Boltzmann(),
        n_epochs=1,
        steps_per_epoch=budget - 1,
        x0=initial.reshape(-1),
    )
    return fitter.finish()
#+end_src

The initial state costs one objective evaluation, hence =budget - 1=
proposals. Mirror reflection keeps every position inside =low= and =high=.
The expression =positions.reshape((n_atoms * 3))= without assignment has no
effect and is not needed.

The feature check supports both lifecycles: =evaluate=/=step= in current
ChemFit and =ask=/=tell= in ChemFit 3.1. An exception from =evaluate= inside
=run= is scored as the worst value and reported once as a =RuntimeWarning=.

For a general nested parameter dictionary, flatten =fitter.initial_parameters=
and =fitter.bounds= with ChemFit's own =flatten_dict= ordering, pass that
initial vector as =x0=, and reconstruct each objective vector with the matching
=unflatten_dict=. Every scalar leaf needs a finite lower and upper bound.

=anneal.chemfit.fit_anneal=, =fit_chemfit=, =run_benchmark= and =run_fitter=
do all of this for any nested parameter dictionary. They make the same
feature check and refuse a fitter with neither pair before =init=. The first
exception the fitter raises, or a loss that is not a real number, stops the
fit: the fitter is not called again, =finish= is skipped, and the exception
reaches the caller.

===================
ChemFit Integration
===================
#+end_export

ChemFit owns parameter reconstruction, callbacks, exception penalties, and
the best evaluated parameter set. =anneal= owns the bounded proposal chain.
Keep those responsibilities separate: call =fitter.step()= exactly once after
each =fitter.evaluate()= and return =fitter.finish()= rather than rebuilding
the result from =History.best_pos=.

For a positions-only fit:

#+begin_src python
import math
from typing import Any

import numpy as np
from anneal import Boltzmann, run


def run_anneal(benchmark_context: dict[str, Any]):
    fitter = benchmark_context["fitter"]
    budget = int(benchmark_context["budget"])
    initial = np.asarray(
        benchmark_context["initial_params"]["positions"],
        dtype=np.float64,
    )
    n_atoms = initial.shape[0]

    if initial.shape != (n_atoms, 3):
        raise ValueError("positions must have shape (n_atoms, 3)")
    if budget < 1:
        raise ValueError("budget must be positive")

    low = np.full(initial.size, -3.0)
    high = np.full(initial.size, 3.0)

    fitter.init()
    if hasattr(fitter, "evaluate"):
        evaluate = fitter.evaluate
        advance = fitter.step
    else:
        evaluate = fitter.ask
        advance = fitter.tell

    def objective(position):
        params = {"positions": np.asarray(position).reshape(n_atoms, 3)}
        loss = evaluate(params)
        advance()
        return float(loss)

    run(
        objective,
        low,
        high,
        Boltzmann(t_init=1.0, sigma=0.1),
        n_epochs=math.ceil(budget / 100),
        steps_per_epoch=100,
        x0=initial.reshape(-1),
        max_evals=budget,
    )
    return fitter.finish()
#+end_src

=max_evals=budget= stops after =budget= evaluations, the initial state
included. The temperature is held for an epoch, so the schedule needs many
epochs: a single epoch of =budget - 1= steps walks at =t_init= throughout and
never cools. =sigma= is in the units of the positions. Mirror reflection
keeps every position inside =low= and =high=.
The expression =positions.reshape((n_atoms * 3))= without assignment has no
effect and is not needed.

The feature check supports both ChemFit's released =ask=/=tell= lifecycle and
the =evaluate=/=step= lifecycle on its custom-optimizer API branch.

For a general nested parameter dictionary, =anneal.chemfit.fit_anneal= does
the flattening: it reads the box from =fitter.bounds=, starts at
=fitter.initial_parameters=, and rebuilds every candidate before ChemFit sees
it, with the same feature check. [[file:../howto/chemfit.org][Optimize through ChemFit]] shows it.

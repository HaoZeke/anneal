* Evaluate a water geometry with CPMD

This tutorial builds rgpot, loads a CPMD engine, and evaluates one water
geometry.
The geometry file is =tests/data/cpmd/water.xyz=.
Its title is =water=.
The atoms are oxygen and two hydrogens, in angstrom, in that order.
The cell is a cube with side 20 angstrom.

** What you will need

- [[https://pixi.sh][pixi]] (manages the full toolchain)

** Clone and build

#+attr_rgpot: syntax
#+begin_src bash
git clone https://github.com/OmniPotentRPC/rgpot.git
cd rgpot
pixi shell -e rpctest
meson setup bbdir -Dwith_tests=true -Dwith_rpc=true --buildtype=debug
meson compile -C bbdir
#+end_src

A tests build produces the stand-in engine and the server:

#+attr_rgpot: output paths of the built engine and server
#+begin_example
bbdir/CppCore/libcpmdc_fake_engine.so
bbdir/CppCore/potserv
#+end_example

** Evaluate water

#+attr_rgpot: syntax
#+begin_src bash
export RGPOT_CPMD_ENGINE="$PWD/bbdir/CppCore/libcpmdc_fake_engine.so"
python tests/cpmd_water.py \
  --server-bin ./bbdir/CppCore/potserv \
  --expect 0.77
#+end_src

The command prints:

#+attr_rgpot: output tests/cpmd_water.py with the stand-in engine
#+begin_example
water geometry: water
water energy: 0.77
#+end_example

The script asks for the energy in eV.
The stand-in engine does not compute an energy from the geometry.
Its energy is 0.75 plus 0.001 times the last entry of the cell (the z length),
so the 20 angstrom cell gives 0.77 eV.
=--expect= makes the script exit with status 1 when the energy differs from the
given value by more than 1e-12.
Point =RGPOT_CPMD_ENGINE= at a =libcpmdc.so= built from the CPMD archive to
evaluate the same file with CPMD, and leave out =--expect=.
Read the energy the command prints.

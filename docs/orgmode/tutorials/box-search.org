#+begin_export rst
==========
Box Search
==========
#+end_export

A bound-constrained design vector is not a point set.
=ensemble_optimize= is the entry: with a gradient it hops and
quenches. Without a gradient, one replica is the values-only
portfolio; more than one replica is a communicating values-only
chain.

#+begin_src python
import numpy as np
from anneal import ensemble_optimize

def sphere(x):
    x = np.asarray(x, dtype=float)
    return float(np.dot(x, x))

def sphere_g(x):
    return 2.0 * np.asarray(x, dtype=float)

low = np.full(6, -2.0)
high = np.full(6, 2.0)
out = ensemble_optimize(
    sphere, low, high, budget=400, seed=3, grad_fn=sphere_g, replicas=2
)
print(out["charged"], round(out["best_val"], 6), out["best_pos"].shape)
#+end_src

=best_pos= has length 6. The design dimension is never rewritten as
\(3N\).

Without =grad_fn= and with one replica the same call is the
values-only portfolio (no hop history):

#+begin_src python
out = ensemble_optimize(sphere, low, high, budget=400, seed=3, replicas=1)
assert out["history_minima"] == 0
#+end_src

The hop primitive is =box_ensemble_optimize=. It requires =grad_fn=
and returns =n_evals=, =n_grads=, =hops=, and =history_minima= instead
of a single =charged= count. Communicating replicas share one
=MinimumHistory= through a Euclidean witness.

Cluster geometries use =cluster_search=, not this page.

Install the package, then run a 38-point Lennard-Jones search with the measured configuration.

#+begin_src bash
pip install anneal
#+end_src

#+begin_src python
import numpy as np
from anneal import Config, cluster_search

def lj(x):
    p = x.reshape(-1, 3)
    d = p[:, None] - p
    r2 = (d * d).sum(-1)
    iu = np.triu_indices(len(p), 1)
    inv6 = (1.0 / r2[iu]) ** 3
    return float(4.0 * np.sum(inv6 * inv6 - inv6))

def lj_g(x):
    p = x.reshape(-1, 3)
    d = p[:, None] - p
    r2 = (d * d).sum(-1)
    np.fill_diagonal(r2, np.inf)
    inv2 = 1.0 / r2
    inv6 = inv2 ** 3
    c = 24.0 * inv2 * (2.0 * inv6 * inv6 - inv6)
    return np.einsum("ij,ijk->ik", c, d).ravel()

cfg = Config.recommended(38)
out = cluster_search(lj, lj_g, cfg.n_points, 4000, seed=0, recommended=True)
print(out["hops"], round(out["best_energy"], 3), len(out["best"]))
# derived=True selects Config.derived(n). ras=True is residual archive search.
# communicating=True selects Config.communicating(n).
# species and sigmas add a diameter-aware swap. rigid=True is a 6N chart.
#+end_src

A binary cluster passes one species label and one diameter per atom.
=sigmas= must be the same length as =species=. =target= ends the search
when a recorded energy reaches it.

#+begin_src python
binary = cluster_search(
    lj, lj_g, 13, 6000, seed=0, recommended=True,
    species=[1] * 6 + [2] * 7,
    sigmas=[1.0] * 6 + [1.3] * 7,
)
#+end_src

A rigid chart uses centre and Rodrigues coordinates. =n= is the number of
bodies. =layout="block"= stores every centre, then every rotation.
=layout="interleaved"= is centre then angle-axis per body, and the
rotations are negated at the boundary. The orientation step turns every
body and leaves the centres where they are. On a chart of more than ten
bodies the acceptance factor stays at or below 4; a ten-body chart may
still climb to 24. Preset temperature, screen length, relax length, and
record gradient are unchanged.

#+begin_src python
water = cluster_search(
    energy, gradient, 10, 20000, seed=0, recommended=True,
    rigid=True, layout="block", target=-391.0216842125,
)
#+end_src

* Direct quantum-chemistry profiles

The molecular-cluster and slab examples use the same persistent
=ProfileEngine=. The adapter loads a conforming potential library once, turns
each energy-and-force result into the optimizer's value-and-gradient pair, and
owns the session for the full hop loop. Selecting =nwchemc= calls
=libnwchemc= in process; no RPC server or result cache participates. Molecular
requests omit a simulation cell and slab requests carry their periodic cell
through the same request type.

#+begin_src bash
POTENTIAL_CONFIG=/path/to/PotentialConfig.bin \
POTENTIAL_LIBRARY=/path/to/libnwchemc.so \
cargo run --locked --release --features rgpot-ex \
  --example molecular_cluster -- 6 1200 8 nwchemc
#+end_src

The shared adapter is =examples/common/profile_engine.rs=. The molecular and
periodic consumers are =examples/molecular_cluster.rs= and
=examples/slab_adsorption.rs=.

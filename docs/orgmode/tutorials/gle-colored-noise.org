* GLE Colored-Noise Langevin

GLE-Langevin combines gradient-driven motion with a generalized Langevin
equation thermostat. Auxiliary momenta give its friction frequency dependence.
The fitted drift matrix is used by the standalone GLE driver and its portfolio
arm; it is not an escape operator in the communicating box or atomic chains.

#+begin_export rst
.. admonition:: Reference

   src/methods/gle_langevin.rs owns the BAB stepping loop and retained
   thermostat state. eindir's GleThermostat and optimal_sampling_drift
   provide the thermostat construction and update. Reusable primitives
   do not establish that every search driver calls them.
#+end_export

* Prerequisites

Gradient of the objective required.
Bounds.

* Step 1: Define obj + grad

#+begin_src python
import numpy as np
from anneal import gle_langevin

def rastrigin(x):
    return 10.0 * len(x) + np.sum(x*x - 10.0 * np.cos(2.0 * np.pi * x))

def grad_rastrigin(x):
    return 2.0 * x + 20.0 * np.pi * np.sin(2.0 * np.pi * x)

low = np.full(5, -5.0)
high = np.full(5, 5.0)
x0 = np.full(5, 2.5)
#+end_src

* Step 2: Call =gle_langevin= (the exposed driver)

#+begin_src python
res = gle_langevin(rastrigin, grad_rastrigin, low, high,
                   max_fevals=4000, seed=11,
                   omega0=0.2, dt=0.2, n_epochs=40, x0=x0)
print("Initial value:", rastrigin(x0))
print("GLE best pos:", res["best_pos"])
print("GLE best val:", res["best_val"])
print("Gradient calls:", res["n_evals"])
print("Combined work:", 2 * res["n_evals"] - res["n_preconditioner_grads"])
print("Effective timestep:", res["dt"])
#+end_src

The initial value is 131.25. The result retains its best observed point, so its
reported value cannot exceed that finite initial value. Starting at the box
centre would start Rastrigin at its global minimum and would not test descent.
This example does not compare white and colored noise or establish a search
advantage. =max_fevals= is a gradient-call allowance for this driver, not the
combined objective-plus-gradient budget used by the box ensemble. With a
supplied frequency, each gradient has a paired objective call. Automatic
calibration adds gradient-only probes, counted in =n_preconditioner_grads=.
The returned timestep includes the driver's frequency-resolution limit.

* Step 3: The thermostat inside (what the algebra buys)

- =eindir= builds the =optimal_sampling_drift= matrix A for the chosen =omega0=.
- The GLE move kernel (B-A-B splitting + exact matrix exponential; the propagator from the GLE literature) occupies the Move slot.
- The standalone driver retains physical and auxiliary momenta between epochs.
- A separate driver invocation initializes a separate thermostat state,
  including separate invocations of the portfolio arm.

Initialization samples the augmented state once. A temperature change rescales
every row by =sqrt(T_new/T_old)= without drawing a replacement. Keeping the
auxiliary rows preserves their correlated history across the annealing epochs.

* What the example establishes

The example exercises a bounded, gradient-enabled GLE search from a nonoptimal
point. Its position update clips to the box; that boundary rule is not a
general manifold retraction or a proof of proposal symmetry. A white/colored
comparison needs matched starts, actual callback budgets, timesteps,
temperature schedules, constraints and polishing rules. Communication needs
its own private/shared comparison with those search settings held fixed.

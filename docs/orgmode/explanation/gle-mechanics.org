See the dedicated tutorial [[file:../tutorials/gle-colored-noise.org][gle-colored-noise]] for the call site and the "one drift serves all" claim.

The construction (white-noise critically damps one frequency; GLE uses ns auxiliary momenta + optimal_sampling_drift matrix A so the spectrum is flat on [omega0, 100*omega0], BAB propagator, stationary reseed, exact matrix_exp + ldl_sqrt) lives in =eindir= (GleThermostat) and is consumed verbatim by =src/methods/gle_langevin.rs=.

Because the GLE object is a pure filling of the Move slot, any future improvement to the thermostat (different canonical form, a-la-carte correctness vs acceleration, new drift fitting) instantly benefits every gradient driver without touching the classical presets or the orchestrator.

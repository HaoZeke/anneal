#+TITLE: Architecture

* Layout

#+BEGIN_EXAMPLE
anneal/
  Cargo.toml          Rust crate (lib + cdylib + staticlib)
  src/                Rust source
  include/            hand-written C++ companion header
  python/anneal/      Python package (mixed maturin layout)
  pytest/             pytest suite
  docs/               this documentation
#+END_EXAMPLE

* Crate types

The Rust crate produces three artefacts:

- =rlib= for downstream Rust consumers
- =cdylib= for Python (=pyo3=) and C dynamic loading
- =staticlib= for C/C++ static linking

* Bindings

- *Python.* =anneal._core= is the Rust extension; the user-facing
  package =anneal= re-exports both Rust types and pure-Python
  helpers from a mixed-mode maturin layout.
- *C.* =cargo-c= produces =anneal-core.h= and
  =libanneal_core.{a,so}= with =pkg-config= integration via
  =anneal-core.pc=.
- *C++.* The hand-written =include/anneal-core.hpp= wraps the C ABI
  in =namespace anneal= for ergonomic C++ use.

* Method Families

- *Component presets.* =Boltzmann=, =Fast=, and =Gsa= instantiate the
  five typed SA signatures directly.
- *Bayesian BGSA.* The CUTEst auto portfolio screens HMC, PT-hybrid,
  Bayesian-mixing, metadynamics, and local-polish candidates under one
  objective interface.
- *QMC polish.* =qmc_polish= and =shifted_qmc_polish= use bounded
  low-discrepancy designs from =eindir= and expose replicated shifts
  through the Python API.
- *Tensor independence.* =additive_independence= fits a rank-1
  additive/tensor surrogate and samples tempered independence
  proposals corrected against the true objective.
- *Colored-noise dynamics.* =gle_langevin= uses a generalized
  Langevin thermostat with an optimal-sampling drift matrix from
  =eindir=.

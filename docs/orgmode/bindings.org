#+TITLE: Bindings

* Python (maturin)

The Python package =anneal= ships from PyPI as a maturin-built wheel.
The Rust extension is exposed as the submodule =anneal._core=.
The package source lives at =python/anneal/= in the repo and is installed via =maturin develop --features python= during development.
The classes, functions, type stubs and exceptions are described in [[file:reference/python-api.org][Python API]].

* C and C++ (cargo-c)

The Rust crate produces a =cdylib=, =staticlib=, generated header =anneal-core.h=, and pkg-config metadata =anneal-core.pc= via cargo-c.

#+BEGIN_SRC bash
cargo cinstall --release --prefix /usr/local
pkg-config --cflags --libs anneal-core
#+END_SRC

A hand-written companion header =anneal-core.hpp= wraps the C declarations in =namespace anneal= for ergonomic C++ usage.

=anneal_box_minimize= reads =ANNEAL_SUCCESS= from a callback as "keep
going". =ANNEAL_STOPPED= asks the search to return at once: the best point
found is written back, and the call itself returns =ANNEAL_STOPPED=. Any
other status is a failure and leaves the start in place. The variants live
in the generated =anneal-core.h=.

** Every box-ensemble setting

=anneal_box_config_t= carries ten settings. The ensemble has more, and
the same ones the Python =box_ensemble_optimize= wrapper takes are in
=anneal_box_options_t=: the history (=ANNEAL_BOX_HISTORY_NONE=,
=_PRIVATE=, =_SHARED=), the membership rule, the identity tolerance, the
shared deposits, the visit policy, the Langevin friction, and the coverage
sharing, peer weight and neighbourhood. =anneal_box_options_default= fills
the structure with the Rust defaults, so a run that changes nothing
reproduces =anneal_box_minimize= with a default =anneal_box_config_t=,
step for step. =anneal_box_minimize_ex= takes it, and an optional
=anneal_box_stats_t= that reports the history and coverage counters.
Every counter of the Python =box_ensemble_optimize= result is there. The
coverage counters of the exchange are the =coverage_*= fields; the Python
=coverage_regions_per_chain= list, which cannot be summed, is its
largest and smallest entry as =coverage_regions_largest= and
=coverage_regions_smallest=. The last field, =coverage_decisions=, is an
=anneal_box_coverage_decisions_t= with the conditional influence of imported
coverage heights on acceptance: the counts of comparisons, their peer
overlaps and probability changes, and the sum and largest of those changes.

The fields of =anneal_box_stats_t= come in two layouts, and a field never
moves when a layout is added. A program built against the first header
reads the first layout and nothing else.

- first layout, 17 words :: =struct_size=, =value=, =n_evals=, =n_grads=,
  =hops=, =history_observations=, =history_minima=, =history_refusals=,
  =history_seconds=, =shared_deposits=, =coverage_observations=,
  =coverage_published=, =coverage_applied_foreign=,
  =coverage_capped_foreign=, =coverage_recrossings=,
  =coverage_novel_arrivals= and =coverage_repelled_proposals=.
- second layout, 42 words in all :: =coverage_peer_recrossings=,
  =coverage_peer_only_recrossings=, =coverage_escape_updates=,
  =coverage_novelty_updates=, =coverage_published_samples=,
  =coverage_applied_foreign_samples=, =coverage_sample_peer_checks=,
  =coverage_sample_anchor_overlaps=,
  =coverage_sample_anchor_only_overlaps=, =coverage_sample_overlaps=,
  =coverage_constrained_repulsions=, =coverage_regions_largest=,
  =coverage_regions_smallest= and =coverage_decisions=.

The library copies the first =struct_size= bytes of its own structure into
the caller's, so a =struct_size= of =sizeof= in either header is safe, and
nothing is written past the caller's structure. A =struct_size= below the
offset of =n_evals= is refused. =tests/ffi_smoke.c= pins the offsets of the
first layout.
=coverage_decisions= is an =anneal_box_coverage_decisions_t= of eight
counts and four real numbers.

#+BEGIN_SRC c
anneal_box_options_t options;
anneal_box_stats_t stats;

anneal_box_options_default(&options);
options.seed = 4;
options.identity_tol = 1e-3;
options.coverage_shared = ANNEAL_BOX_COVERAGE_PRIVATE;
stats.struct_size = sizeof stats;
status = anneal_box_minimize_ex(eval, grad, NULL, &tensor, low, high,
                                &options, &stats);
#+END_SRC

The enum-valued fields are =int32_t=, so a value the library does not know
is refused with =ANNEAL_INVALID_PARAMETER= and a message in
=anneal_last_error()=, before any callback runs. Both structures start
with =struct_size=. The library reads only the bytes the caller's
structure has and takes the default for the rest, and writes only the
statistics that fit, so a newer library can add fields at the end without
breaking a program built against this header: a program that was built
before the coverage counters existed gets the statistics it knows, and
nothing is written past its =struct_size=. =tests/ffi_smoke.c= builds
against the installed header, and =scripts/ffi_smoke.sh= runs it from a
checkout. =FFI_SMOKE_VALGRIND=1 scripts/ffi_smoke.sh= runs it under
valgrind, as the ffi job in CI does.

The install also places =dlpack/dlpack.h= (DLPack 1.3, the header =dlpk= 0.1.5 was translated from) on that include prefix. =anneal-core.h= includes it, so =pkg-config --cflags anneal-core= is enough to compile a consumer. Meson and CMake install the same header.

** Reproducible static archive

Meson builds the static archive with
=scripts/meson_cargo_build.py=. Leave
=ANNEAL_REPRODUCIBLE_ARCHIVE= unset for that ordinary build. The
script then forwards the caller's Cargo environment. On hosts where
Meson passes =objcopy= and =nm=, it packs the final object with
=ar crs=. On macOS and Windows it ships Cargo's archive as built.

Set =ANNEAL_REPRODUCIBLE_ARCHIVE=1= to change three things.

Archiver flags. On hosts where Meson passes =objcopy= and =nm=,
the members are joined with =ld -r= and the archive that ships is
packed with =ar crsD= when that archiver accepts =D= (zero mtime,
uid, and gid). An archiver that rejects =D= is packed with =ar crs=
and the member headers are then rewritten to those same zeros. On
that path =AR= is used when it is set, otherwise =ar= on =PATH=,
otherwise =llvm-ar=. On macOS and Windows, Meson passes an empty
=objcopy= and =nm=, so no archiver runs: the copied Cargo archive's
headers are rewritten in process and =AR= is ignored.

Remapped prefixes. Cargo runs with =CARGO_INCREMENTAL=0= and
=-Ccodegen-units=1=. =--remap-path-prefix= sends the source tree to
=/source=, the Cargo target directory to =/build=, and
=CARGO_HOME= (or =~/.cargo= when it is unset) to =/cargo=. When
several prefixes match a path, rustc applies the last matching
flag. The script passes them shortest first, so the most specific
one wins: a target directory inside the source tree maps to
=/build=, not =/source/target=.

=CARGO_ENCODED_RUSTFLAGS= merge. When that variable is set, even
to empty, its unit-separator list is kept and =RUSTFLAGS= is not
read. Otherwise =RUSTFLAGS= is split on spaces. The remap flags
are appended, and the whole list is written back as
=CARGO_ENCODED_RUSTFLAGS=. Cargo honours that form when both
variables are set, so a flag that contains a space survives.

Export the variable for =meson compile=. Setup does not run the
archive script. Ninja does not track the variable either, so after
changing it in an existing build directory run =meson compile
--clean= first, or use a fresh build directory. Compare two
checkouts at different paths. Pass
debug info so the source path is actually in the objects; a
release build often has none, and then =cmp= can match even when
the prefixes were not rewritten.

#+BEGIN_SRC bash
export ANNEAL_REPRODUCIBLE_ARCHIVE=1
export CARGO_ENCODED_RUSTFLAGS=-Cdebuginfo=2
meson setup build-repro
meson compile -C build-repro
#+END_SRC

Run the same commands in the second checkout, then:

#+BEGIN_SRC bash
cmp "$A/build-repro/libanneal_core.a" \
    "$B/build-repro/libanneal_core.a"
strings "$A/build-repro/libanneal_core.a" | grep -F /source
strings "$A/build-repro/libanneal_core.a" | grep -F "$A"
#+END_SRC

=cmp= exits 0 when the archives match. =grep= should find
=/source= and should not find the checkout path. On Windows the
file is =anneal_core.lib=. On GNU =ar= 2.42, =D= is already the
default, so two builds of one tree match without the variable.
The two-checkout comparison is the check that the remap and the
final archive step agree.

** Tiny C example (box ensemble)

The objective and its gradient are DLPack callbacks. =x= goes in as the
first replica's start and comes back as the best point.

#+BEGIN_SRC c
#include <anneal-core.h>
#include <stdio.h>

static enum anneal_status_t sphere(void *user,
                                   const DLManagedTensorVersioned *x,
                                   double *value_out) {
    const double *v = (const double *)x->dl_tensor.data;
    (void)user;
    *value_out = v[0] * v[0] + v[1] * v[1];
    return ANNEAL_SUCCESS;
}

static enum anneal_status_t sphere_grad(void *user,
                                        const DLManagedTensorVersioned *x,
                                        DLManagedTensorVersioned *grad_out) {
    const double *v = (const double *)x->dl_tensor.data;
    double *g = (double *)grad_out->dl_tensor.data;
    (void)user;
    g[0] = 2.0 * v[0];
    g[1] = 2.0 * v[1];
    return ANNEAL_SUCCESS;
}

static void point_at(DLManagedTensorVersioned *t, double *data,
                     int64_t *shape, int64_t *strides, int64_t n) {
    shape[0] = n;
    strides[0] = 1;
    t->version.major = 1;
    t->version.minor = 0;
    t->manager_ctx = NULL;
    t->deleter = NULL;
    t->flags = 0;
    t->dl_tensor.data = data;
    t->dl_tensor.device.device_type = kDLCPU;
    t->dl_tensor.device.device_id = 0;
    t->dl_tensor.ndim = 1;
    t->dl_tensor.dtype.code = kDLFloat;
    t->dl_tensor.dtype.bits = 64;
    t->dl_tensor.dtype.lanes = 1;
    t->dl_tensor.shape = shape;
    t->dl_tensor.strides = strides;
    t->dl_tensor.byte_offset = 0;
}

int main(void) {
    double x[2] = {1.5, -1.0};
    int64_t shape[1], strides[1];
    DLManagedTensorVersioned tensor;
    double low[2] = {-5.0, -5.0};
    double high[2] = {5.0, 5.0};
    struct anneal_box_config_t cfg;
    struct anneal_box_report_t report;
    enum anneal_status_t status;

    point_at(&tensor, x, shape, strides, 2);
    if (anneal_box_config_default(&cfg) != ANNEAL_SUCCESS)
        return 1;
    cfg.seed = 1;
    status = anneal_box_minimize(sphere, sphere_grad, NULL, &tensor,
                                 low, high, &cfg, &report);
    printf("%s status %d value %.6f at (%.4f, %.4f)\n",
           anneal_core_version(), (int)status, report.value, x[0], x[1]);
    return status == ANNEAL_SUCCESS ? 0 : 1;
}
#+END_SRC

** Tiny C++ example (using the hand-written header)

Compiled as C++, the generated declarations live in =namespace anneal=.
=anneal::version()= is the hand-written wrapper.

#+BEGIN_SRC cpp
#include <anneal-core.hpp>
#include <iostream>

static anneal::anneal_status_t sphere(void *, const DLManagedTensorVersioned *x,
                                      double *value_out) {
    const double *v = static_cast<const double *>(x->dl_tensor.data);
    *value_out = v[0] * v[0] + v[1] * v[1];
    return anneal::ANNEAL_SUCCESS;
}

static anneal::anneal_status_t sphere_grad(void *, const DLManagedTensorVersioned *x,
                                           DLManagedTensorVersioned *grad_out) {
    const double *v = static_cast<const double *>(x->dl_tensor.data);
    double *g = static_cast<double *>(grad_out->dl_tensor.data);
    g[0] = 2.0 * v[0];
    g[1] = 2.0 * v[1];
    return anneal::ANNEAL_SUCCESS;
}

static void point_at(DLManagedTensorVersioned *t, double *data,
                     int64_t *shape, int64_t *strides, int64_t n) {
    shape[0] = n;
    strides[0] = 1;
    t->version.major = 1;
    t->version.minor = 0;
    t->manager_ctx = nullptr;
    t->deleter = nullptr;
    t->flags = 0;
    t->dl_tensor.data = data;
    t->dl_tensor.device.device_type = kDLCPU;
    t->dl_tensor.device.device_id = 0;
    t->dl_tensor.ndim = 1;
    t->dl_tensor.dtype.code = kDLFloat;
    t->dl_tensor.dtype.bits = 64;
    t->dl_tensor.dtype.lanes = 1;
    t->dl_tensor.shape = shape;
    t->dl_tensor.strides = strides;
    t->dl_tensor.byte_offset = 0;
}

int main() {
    double x[2] = {1.5, -1.0};
    int64_t shape[1], strides[1];
    DLManagedTensorVersioned tensor{};
    double low[2] = {-5.0, -5.0};
    double high[2] = {5.0, 5.0};
    anneal::anneal_box_config_t cfg{};
    anneal::anneal_box_report_t report{};
    point_at(&tensor, x, shape, strides, 2);
    if (anneal::anneal_box_config_default(&cfg) != anneal::ANNEAL_SUCCESS)
        return 1;
    cfg.seed = 1;
    auto status = anneal::anneal_box_minimize(
        sphere, sphere_grad, nullptr, &tensor, low, high, &cfg, &report);
    std::cout << anneal::version() << " value " << report.value
              << " at " << x[0] << "," << x[1] << "\n";
    return status == anneal::ANNEAL_SUCCESS ? 0 : 1;
}
#+END_SRC

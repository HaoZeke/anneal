* Optimize through ChemFit

[[https://chemfit.readthedocs.io][ChemFit]] evaluates a loss for a nested parameter dictionary and keeps
the best evaluated parameters. Its =Fitter= exposes a user-driven loop,
=init()=, =evaluate()=, =step()= and =finish()= (=ask()= and =tell()= in
ChemFit 3.1), so an anneal driver can propose the parameters while ChemFit
evaluates and records them. The [[file:../tutorials/chemfit.org][ChemFit tutorial]] writes that loop by
hand; the bridges in =anneal.chemfit= write it for you.

=run=, =run_qmc=, =global_optimize= and =qmc_gsa_global_search= call the
objective only inside =[low, high]= and start at =x0= when it is given. Before
0.10.0, =Boltzmann=, =Fast= and =Gsa= drew only their start from the box; a
13-atom walk in =[-3, 3]= evaluated 99.95% of its points outside it.

** From a fitter

#+begin_src python
from anneal.chemfit import fit_anneal

fitter = Fitter(
    objective,
    initial_params={"positions": initial_positions},
    bounds={"positions": (-3.0, 3.0)},
)
best = fit_anneal(
    fitter,
    10_000,
    driver="boltzmann",
    preset_kwargs={"t_init": 1.0, "sigma": 0.1},
)
#+end_src

=fit_anneal= reads the box from =fitter.bounds=, where a scalar pair covers a
whole array leaf and a leaf without bounds gets =x0= plus or minus
=bound_span=. It starts at =fitter.initial_parameters=, or at =x0=, given as a
dictionary of the same shape or a flat vector, follows every evaluation with
=step()=, and returns =fitter.finish= of the best point. =driver= is
="portfolio"= (=global_optimize=, the default), ="boltzmann"=, ="fast"= or
="gsa"=; a preset's =sigma= or =gamma= is in the units of the parameters. The
portfolio makes at most =budget= evaluations and the classical drivers make
exactly =budget=, the start included, with the cooling schedule spread over
=ceil(budget / steps_per_epoch)= epochs.

=fit_chemfit= flattens with ChemFit's dotted keys and calls =step()= every
=tell_every= portfolio evaluations. =run_benchmark= takes a benchmark's
context dictionary as it is:

#+begin_src python
from anneal import Boltzmann
from anneal.chemfit import run_benchmark


def run_anneal(benchmark_context):
    return run_benchmark(
        benchmark_context,
        method="boltzmann",
        preset=Boltzmann(t_init=1.0, sigma=0.1),
        low=-3.0,
        high=3.0,
    )
#+end_src

All three call =evaluate= and =step= when the fitter has them and =ask= and
=tell= otherwise. When every evaluation raises, for instance because the
fitter has neither, the first exception is re-raised rather than reported as
a warning.

** Fitter.fit_anneal

[[file:../../../experiments/chemfit/0001-feat-fitter-add-Fitter.fit_anneal.patch][experiments/chemfit/0001-feat-fitter-add-Fitter.fit_anneal.patch]]
with [[file:../../../experiments/chemfit/0002-fix-fitter-make-fit_anneal-follow-the-fitter-s-polic.patch][0002]] and [[file:../../../experiments/chemfit/0003-fix-fitter-validate-seed-and-preset-in-fit_anneal-and.patch][0003]]
add =Fitter.fit_anneal= to ChemFit 4 (=git am= all three onto ChemFit's =next=;
the extra requires anneal 0.10.0 or later). It takes the box from
=Fitter.bounds=, including array leaves with scalar or per-element bounds, and
holds a coordinate with equal bounds fixed. It evaluates =initial_params=
exactly first, makes exactly =budget= evaluations, calls =step()= after each,
and returns the best parameters evaluated in this fit.

#+begin_src python
best = fitter.fit_anneal(budget=10_000, method="gsa")
#+end_src

=method= is ="portfolio"= (=global_optimize=, the default), ="boltzmann"=,
="fast"=, ="gsa"= or ="gpmd"=; the portfolio and gpmd are restarted from the
best point until the budget is spent. The parameters are passed to anneal in
the unit cube, so a preset's step is in units of each box width; the
temperature is in loss units. An exception from the objective, from a
callback in =step()= or from =gradient= follows the fitter's
=swallow_exceptions= and =log_exceptions=: when it is re-raised, the fit stops
at that evaluation.

[[file:../../../experiments/chemfit/bridge_check.py][experiments/chemfit/bridge_check.py]] runs every path on this page on one
ChemFit 4 fitter. At a budget of 2000, each made exactly 2000 evaluations,
none outside the box, the first at the initial positions; the loop from the
original report made 2001 from a uniform start.

** What to expect on a positions benchmark

Thirteen Lennard-Jones atoms in =[-3, 3]^{39}=, started from uniform
positions in =[-1.6, 1.6]=, five seeds, the median of the best energy
ChemFit recorded (the global minimum is \(-44.327\)). Measured with
[[file:../../../experiments/chemfit/positions_benchmark.py][experiments/chemfit/positions_benchmark.py]].

| Driver                                  | 2000 evaluations | 10000 evaluations |
|-----------------------------------------+------------------+-------------------|
| Nevergrad CMA                           |          \(-31.1\) |           \(-40.7\) |
| Nevergrad NgIohTuned                    |          \(-30.9\) |           \(-39.2\) |
| anneal =cluster_search=, difference gradients |    \(-36.5\) |           \(-39.5\) |
| SciPy L-BFGS-B, difference gradients    |          \(-30.4\) |           \(-38.8\) |
| anneal =dmc_population_optimize=        |          \(-20.4\) |           \(-34.1\) |
| anneal =Gsa=                            |          \(-13.5\) |           \(-32.5\) |
| anneal =gpmd_optimize=                  |          \(-25.3\) |           \(-31.3\) |
| anneal =Boltzmann=, =sigma=0.1=         |          \(-21.4\) |           \(-24.4\) |
| anneal =global_optimize=, values only   |          \(-11.5\) |           \(-24.7\) |

These drivers see raw coordinates. Every one uses function values only, the
difference gradients included: at 2000 evaluations =cluster_search= on
difference gradients is the strongest, and at 10000 CMA-ES is. The classical
presets are the simulated-annealing comparison, not the fastest descent.
Energies come with forces in ChemFit's ASE objectives; given a gradient,
=cluster_search= on atomic positions, or =global_optimize= with =grad_fn=,
uses it. =cluster_search= draws its own starts in its own box, so it does not
take =x0= or a user box.

Through =Fitter.fit_anneal=, on the same starts and seeds with
=bounds={"positions": (-3, 3)}=, the search runs in the unit cube and every
method makes exactly the budget of evaluations
([[file:../../../experiments/chemfit/positions_fit_anneal_2000.jsonl][2000 rows]], [[file:../../../experiments/chemfit/positions_fit_anneal_10000.jsonl][10000 rows]]):

| =method=      | 2000 evaluations | 10000 evaluations |
|---------------+------------------+-------------------|
| ="gsa"=       |        \(-24.9\) |         \(-32.7\) |
| ="gpmd"=      |        \(-25.3\) |         \(-31.3\) |
| ="boltzmann"= |        \(-20.2\) |         \(-22.3\) |
| ="portfolio"= |        \(-15.6\) |         \(-16.2\) |
| ="fast"=      |        \(-12.1\) |         \(-16.3\) |

For a smooth positions fit, pass =method="gsa"= or =method="gpmd"=. The
default portfolio spreads the budget over restarts and population arms meant
for rugged surfaces and ends far above them here.

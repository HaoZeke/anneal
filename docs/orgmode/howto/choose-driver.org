* Decision Tree

The first split is geometry, not "LJ versus CUTEst". A point set
in \(\mathbf{R}^{3N}\) is a cluster. A bound-constrained design
vector is a box. Then split on whether a gradient exists.

Ask in order:

1. Is the state a point set (\(N\) atoms, length \(3N\))?
   - Yes → =cluster_search= with =Config.recommended(n)=.
     Use =derived=True= for the cost-asymmetric screen.
     Use =ras=True= for residual archive search.
     See [[file:../tutorials/cluster-search.org][cluster search]].
   - No, it is a design box → 2.

2. Do you have a native gradient on that box?
   - Yes → =ensemble_optimize(..., grad_fn=...)=.
     Kick, quench, shared Euclidean =MinimumHistory=.
     The hop primitive is =box_ensemble_optimize= (requires =grad_fn=).
     See [[file:../tutorials/box-search.org][box search]].
   - No → =ensemble_optimize(..., replicas=1)= is the values-only
     portfolio. Default =replicas=4= without a gradient is a
     communicating values-only chain. Use =global_optimize= when you
     want portfolio arms rather than hops.

   ChemFit is a design box. Call =anneal.minimize= with =replicas=
   and =store= (HDF5 file or an existing readcon-db campaign directory).
   See [[file:chemfit.org][ChemFit]]. Do not use =cluster_search=.

3. Do you want the typed SA algebra (Cool / Move / Accept) on a box?
   - Values only → =run= with Boltzmann / Fast / Gsa.
   - Separable → =additive_independence=.
   - Ill-conditioned spectrum and a gradient → =gle_langevin=.
   - GPU or many independent chains → =run_device= / =run_ensemble=
     (batched SA, not communicating hops).

4. Last mile after any of the above?
   - =polish= / =qmc_polish= / =shifted_qmc_polish=:
     bounded L-BFGS (two-loop, Armijo backtrack, active-set projection).
   - Cluster quench is =WarmLbfgs= → =rgmin::Lbfgs= (strong Wolfe).
     See [[file:rgmin-lbfgs.org][local polish through rgmin]].

Full details on supplying native gradients live in the
[[https://eindir.rgoswami.me/howto/gradients.html][eindir gradients guide]].

Do not pad a design vector to \(3N\) to reuse cluster moves.
Do not call =Config.recommended= on a box.

The exposed high-level functions already encode the common good choices.
The Bayesian mixer (one =max_proposals=, Thompson across families)
still lives in =experiments/scripts/demo_bgsa.py= and the
[[file:../tutorials/bayesian-pilot-mixer.org][Bayesian tutorial]].

* Fitting through ChemFit

For a gradient-free fit, use =anneal.chemfit.fit_anneal(fitter, budget, driver=...)=.
The default =driver="portfolio"= allocates the gradient-free arms.
=driver="boltzmann"=, ="fast"=, or ="gsa"= is the single-chain ablation.
The fitter's initial parameters are the start, bounds come from the fitter
or from =low= / =high=, and every evaluation stays in the box.
=fit_chemfit= is the same protocol with dotted-key flattening, and
=run_benchmark= also accepts =evaluate= / =step=.
See =examples/chemfit_positions.py= and =examples/chemfit_anneal.py=.

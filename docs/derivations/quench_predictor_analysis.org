#+TITLE: Analysis of the geometric early-stop predictor for charged screening quenches
#+OPTIONS: toc:2 num:t
#+STARTUP: showall

* Abstract

The =anneal= screening path charges every gradient evaluation on a finite
work ledger. Measured on LJ38, 89--92% of the charged budget is spent in
screening quenches of fixed length. This note analyses the *implemented*
early-stop rule (=src/quench.rs=, =QuenchPredictor=) in the style of ACM
TOMS algorithm papers (e.g. Hager--Zhang CG_DESCENT: state the algorithm,
prove a guarantee under explicit hypotheses, bound cost). The guarantee is
not global optimality of cluster search; it is *soundness of a Hopeless
verdict under the geometric-decrement model that the code fits*, and an
evaluation upper bound relative to a fixed-length screen.

* 0. Outcome: the hypothesis is false on this landscape

The analysis below is sound and the rule it analyses is off, because the
geometric-decrement model the code fits does not describe a real quench from
a perturbed cluster. Scoring each extrapolation against the value the full
twenty-five step screen reaches, without acting on it:

| warmup | stop step | mean abs. error |
|--------+-----------+-----------------|
|      4 |       4.2 |         12442.4 |
|      8 |       8.4 |           992.7 |
|     12 |      12.4 |            19.1 |
|     16 |      16.1 |             3.6 |

Minima near the bottom of the LJ38 landscape are separated by well under one
unit, so a usable energy costs about twenty of the twenty-five steps and the
rule saves nothing. Acting on it, eight seeds solved nothing where the
fixed-length control solved eight: a chain given energies wrong by four
orders of magnitude rejects every proposal, which is why it produced four
times the hops and no progress.

The premise is what this refutes. The screening pass looked like overhead at
89--93% of the charged budget against 8% for the relaxations it guards. It is
not overhead; it is the quench, and the full relaxation is the polish on the
2% of trials that survive it. Sections 1 onward stand as the analysis of a
rule that is correct about a regime this problem does not enter.

* 1. Problem

A screening quench produces a sequence of energies
\(E_0,E_1,\ldots,E_{n-1}\) by successive descent steps. The screen asks
whether the *limit* of this quench can beat an incumbent value
\(E_{\mathrm{best}}\). A fixed iteration cap answers only after a
predetermined number of charged evaluations. The predictor answers from a
short prefix when the geometric model applies.

* 2. Algorithm (as implemented)

#+BEGIN_SRC text
Algorithm QEP (Quench Early-stop Predictor)
Input: energies E[0..n-1], incumbent B, constants
       warmup w, confidence c, margin m
1. If n < w: return Undecided
2. Form positive decrements d_k = E[k]-E[k+1] for k=0..n-2 with d_k>0;
   set y_k = log d_k. If fewer than 3 points: return Undecided
3. OLS fit: y = α + β k  (minimize Σ (y_k - α - β k)^2)
4. If β ≥ 0: return Undecided  (non-shrinking decrements)
5. r := exp(β); if r ≥ 1: return Undecided
6. s_log^2 := residual mean square (m-2 degrees of freedom)
7. d_fit := exp(α + β k_last);  tail := d_fit * r / (1-r)
8. L := E[n-1] - tail
9. Propagate residual: σ := |tail| * hypot(s_log, se_β * r/(1-r))
10. If L - c σ > B + m: return Hopeless
11. If L + c σ < B - m: return Promising
12. Else: return Undecided
#+END_SRC

Code map: =predict= (steps 1--9), =verdict= (steps 10--12). Constants
default \(w=4\), \(c=2\), \(m=10^{-3}\).

* 3. Exact geometric model

Assume the *truth* is geometric decrements with ratio \(r\in(0,1)\) and
limit \(E_\infty\):
\begin{equation}
  E_k = E_\infty + \frac{d_0\, r^{k}}{1-r}
  \quad\text{equivalently}\quad
  d_k := E_k-E_{k+1} = d_0\, r^{k},\quad d_0>0.
  \tag{Q1}
\end{equation}
Then
\begin{equation}
  \sum_{j\ge k} d_j = d_k\,\frac{r}{1-r},
  \qquad
  E_\infty = E_k - d_k\,\frac{r}{1-r}.
  \tag{Q2}
\end{equation}
This is the identity used in =predict= (with \(d_k\) replaced by the fitted
value at the last index).

** Lemma 1 (log-linearity).
Under (Q1), \(\log d_k = \log d_0 + k\log r\), so the population regression
of \(\log d_k\) on \(k\) has slope \(\beta=\log r<0\) and intercept
\(\alpha=\log d_0\).

**Proof.** Immediate from \(d_k=d_0 r^k\). \(\square\)

** Theorem 1 (exact recovery by OLS).
Given \(m\ge 2\) exact samples \((k_i,\log d_{k_i})\) from (Q1) with distinct
\(k_i\), the unique OLS fit recovers \(\beta=\log r\) and \(\alpha=\log d_0\)
exactly, residual zero, and the constructed limit equals \(E_\infty\).

**Proof.** The design matrix for intercept and slope on two or more
distinct abscissae has full column rank; the population line lies in the
column space; residual is zero; (Q2) with fitted \(d\) and \(r\) recovers
\(E_\infty\). \(\square\)

Executable witness: =proofs/quench_predictor_analysis.py=
=test_exact_geometric_recovery= (matches the unit test in =quench.rs=).

* 4. Soundness of Hopeless under the model

The Hopeless rule is
\begin{equation}
  L - c\,\sigma > E_{\mathrm{best}} + m.
  \tag{Q3}
\end{equation}

** Theorem 2 (no false Hopeless under exact geometry and conservative σ).
Assume (Q1) holds exactly, the OLS residual is zero (so the implementation
returns \(\sigma=0\)), and the verdict is Hopeless with \(c,m\ge 0\). Then
\(E_\infty > E_{\mathrm{best}}\): finishing the quench cannot beat the
incumbent under the true dynamics.

**Proof.** Residual zero \(\Rightarrow\) \(\sigma=0\) in the code's formula
and \(L=E_\infty\) by Theorem 1. Hopeless with \(\sigma=0\) reads
\(E_\infty > E_{\mathrm{best}}+m \ge E_{\mathrm{best}}\). \(\square\)

** Remark (why σ and m exist).**
When the model is approximate, \(\sigma>0\) widens the undecided band.
Hopeless requires the *lower* end of \(L\pm c\sigma\) (actually \(L-c\sigma\))
to clear \(E_{\mathrm{best}}+m\). That is a *one-sided* guard against
discarding an improving trial: the implementation is asymmetric by design
(=verdict= documentation). A full finite-sample guarantee under misspecified
\(r\) would need concentration inequalities on the OLS residual; that is
not claimed here. The theorem states what the code *does* prove under the
model it fits.

** Theorem 3 (Promising under exact geometry).
Under the same exact model with \(\sigma=0\), Promising implies
\(E_\infty < E_{\mathrm{best}}-m\le E_{\mathrm{best}}\).

**Proof.** Dual to Theorem 2. \(\square\)

* 5. Evaluation bound versus fixed-length screen

Let a fixed screen charge \(N_{\mathrm{fix}}\) evaluations (value/gradient
pairs). The predictor after \(n\) observations uses those \(n\) evaluations
already paid; if it returns Hopeless, the remaining \(N_{\mathrm{fix}}-n\)
are not spent on that trial.

** Proposition 4 (savings on Hopeless).
If a trial is declared Hopeless after \(n\le N_{\mathrm{fix}}\) charged
evaluations, the charged cost of that trial is \(n\), not \(N_{\mathrm{fix}}\).
The saving is \(N_{\mathrm{fix}}-n\ge 0\).

This is an accounting identity, not a probabilistic claim. Aggregate
savings equal \(\sum_{\mathrm{Hopeless}}(N_{\mathrm{fix}}-n_i)\). The
empirical 89--92% budget share for screening on LJ38 is the motivation for
driving \(n_i\) down on hopeless trials; Theorems 2--3 bound the *error mode*
of that shortcut under the geometric hypothesis.

* 6. Least-squares residual propagation (as coded)

With fitted slope \(\hat\beta\), intercept \(\hat\alpha\), residual scale
\(s_{\log}\), and
\[
  \mathrm{se}_{\hat\beta} = s_{\log}/\sqrt{S_{xx}},
  \quad
  \hat d = e^{\hat\alpha+\hat\beta k_{\mathrm{last}}},
  \quad
  \widehat{\mathrm{tail}} = \hat d\,\frac{\hat r}{1-\hat r},
  \quad \hat r=e^{\hat\beta},
\]
the code sets
\begin{equation}
  \sigma
  =
  \bigl|\widehat{\mathrm{tail}}\bigr|
  \sqrt{ s_{\log}^{2} + \Bigl(\mathrm{se}_{\hat\beta}\,\frac{\hat r}{1-\hat r}\Bigr)^{2} }.
  \tag{Q4}
\end{equation}
This is a first-order delta-method style combination of multiplicative error
on \(\hat d\) (using \(s_{\log}\) as relative log-error) and sensitivity of
the map \(r\mapsto r/(1-r)\). It is **not** a classical \(t\)-interval for
\(E_\infty\); it is an explicit, reproducible uncertainty functional of the
fit. As \(\hat r\to 1^-\), \(\sigma\to\infty\), correctly refusing a verdict
when the geometric tail is ill-conditioned.

** Lemma 5 (blow-up at flat decay).
If \(\hat r\uparrow 1\) with \(\widehat{\mathrm{tail}}\) and \(s_{\log}\)
bounded away from zero, then \(\sigma\to+\infty\).

**Proof.** Factor \(r/(1-r)\to+\infty\). \(\square\)

* 7. What this is not (TOMS honesty)

| Not claimed | Why |
|-------------|-----|
| Global convergence of basin hopping | Different algorithm; requires landscape hypotheses (Wales, Hajek) |
| False-Hopeless probability under LJ | Model misspecification; needs experiments, not a lemma |
| Competitiveness with L-BFGS-B evaluation counts | Separate issue (=warm_lbfgs.rs= already documents ~10× gap) |
| Optimality of \(c=2\), \(w=4\), \(m\) | Engineering defaults; retune with measurement |

The CG_DESCENT pattern is: prove *descent of the search direction under
Wolfe*, not "we solve every problem." Here: prove *Hopeless does not
discard a better limit under the fitted model when residuals vanish*, and
state the cost accounting.

* 8. Relation to the charged ledger

Every call that produces an energy in the screening trajectory charges the
ledger once (see =cluster_search= / =Ledger::charge=). Early Hopeless
reduces the number of charges *without* changing the definition of a work
unit. Fair comparison of methods still requires charging finished
relaxations the same way; the predictor only changes *how many* units a
failed proposal spends.

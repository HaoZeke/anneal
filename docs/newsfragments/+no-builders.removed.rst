The stock search presets no longer build structures from a template or a recognised motif. Removed: the library reseed moves (``MoveLibrary::{Reseed, SelfReseed, LearnedReseed, GrowthAndTwin}``) with ``crate::construct`` and ``crate::lattice``'s template library, decahedral and pentagonal shells and growth; the chain-level reoccupation, regrowth and successive-placement builders (``Config::reoccupy``, ``reoccupy_interval``, ``construct_width``); orbit completion and core symmetrisation (``orbit_complete_on_new``, ``orbit_arm``, ``orbit_core``/``OrbitCore``, ``point_symmetrise*``, ``symmetrise_on_stall``, ``symmetrise_core_fraction``, ``symmetrise_patience``, ``for_cluster_dual_core``, ``with_dual_orbit_core``, ``ClusterMove::{OrbitComplete, PointSymmetrise}``), with the builders in ``crate::symmetrise`` that fed them. ``crate::symmetrise`` keeps symmetry detection and group closure. ``structure::Template::points`` is crate-private and read only by the PTM matcher. The published Dynamic Lattice Search baseline moved out of the library to ``examples/lj_dls``, with its Table 1 sizes in ``experiments/dls_published/table1.csv``. ``recommended`` and ``for_cluster`` therefore run without orbit completion or stall symmetrisation, which the previous releases enabled.

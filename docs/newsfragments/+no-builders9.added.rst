The symmetry completion of a new basin keeps the species of a structure that has them. ``detected_symmetry::detected_group_classed``, ``complete_orbits_classed`` and ``complete_detected_classed`` (and ``symmetrise::detect_all_classed`` under them) take one class label per point: an operation is detected only when it carries every point onto a point of its own class, each class is merged into sites of its own images, and a class takes the sites it has most support for that are clear of every site already chosen. The search passes ``Config::species``. Before, the group of a binary structure was read as if its atoms were one species, and the completion seated atoms on sites of the other species. The unclassed functions are the same calls with one class, and give the same result as before for a structure without species.

``Config::symmetry_completion_once`` (off in every preset, and absent from the resolved configuration unless set) completes each basin once per chain. A chain without a shared history otherwise runs the detected symmetry completion each time an accepted hop enters a basin, including one it has completed before; with the switch on it skips a basin it has attempted, by the region identity the controller uses. It changes the walk, and the Python cluster ``Config`` reads it as ``symmetry_completion_once``.

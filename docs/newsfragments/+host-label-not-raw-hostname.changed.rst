Bench scripts and board examples no longer write a raw hostname. ``host_label`` in ``scripts/machine_provenance.py`` keeps the sandbox name ``bench`` and turns any other name into a salted digest; shell scripts call ``machine_provenance.py host-label``. The TIP4P rerun drops its ``hostname`` column, so fresh output has the columns of the committed artifacts. A test fails when a script reads the host another way.

``Config::observed_basis_probe`` (on in every preset that ran the observed basis probe, and absent from the resolved configuration while on) switches the one structure the search builds: the compact lattice body grown from the tightest mutually neighbouring tetrahedron of the current geometry on a directed stall. ``src/lattice.rs`` keeps only that probe and the nearest-neighbour scale; the named templates, the decahedral cut and the library of sources are gone. The Python cluster ``Config`` reads the switch as ``observed_basis_probe``.

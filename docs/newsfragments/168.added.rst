``Ledger::keep_recent_evidence(cap)`` keeps only the newest ``cap``
quench boundaries on the ledger and the newest ``cap`` accepted
transitions of a run charged to it. ``Ledger::dropped_quench_boundaries``
and ``Outcome::dropped_transitions`` count the older ones. Without the
call both records grow with the budget, as before. ``h2h_seed`` takes the
cap as an optional ninth argument.

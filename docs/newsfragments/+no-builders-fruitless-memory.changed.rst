The memo of minima whose symmetry completion found nothing now holds each minimum's coordinates and energy instead of its pair-spectrum descriptor. A descriptor is quadratic in the number of points, 25 kB at 80 points and 46 kB at 108, and a chain kept one per fruitless visit for the whole run, which made its resident memory grow faster than a run without the memo. The coordinates are linear in the number of points, like every state kept per accepted edge. The descriptor of a held structure is rebuilt only when its energy matches the one being tested, so every answer, and so every walk, is the one given before.

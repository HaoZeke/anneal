Python bindings: ``Config.orbit_complete_on_new`` is removed and ``Config.symmetry_completion_on_new`` is its replacement; code that read the old name raises ``AttributeError``. The presets that enabled orbit completion now enable the symmetry completion instead: ``Config.recommended``, ``Config.communicating`` and the scaled recommended preset the search entry builds turn it on, and the TIP4P presets (``Config.recommended_tip4p``, ``Config.communicating_tip4p``) leave it off. No other Python name changes.

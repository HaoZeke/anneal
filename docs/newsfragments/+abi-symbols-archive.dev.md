The `abi_symbols` test picks the `nm` mode from the library it is given: `nm -D --defined-only` for a shared object and `nm -g --defined-only` for a static `lib*.a` or `*.lib` archive, which has no dynamic symbol table. macOS still uses `nm -gU`. A small fixture built as a shared object and as both archive kinds runs every mode in every `with_tests` build, and checks that a shared object's hidden names and an archive's missing names still fail.

`docs/doccheck.py` checks the documentation against the source. It requires a reference entry with Inputs, Units, Outputs and Errors for every public C, C++ and Python name, and a classification for every code block in the README and the docs. The C names include the Metatomic and XTB engine tables and the libcp2k API of the GROMACS drop-in. The entry of each `*Config` struct must name every field, a reference page must name every field the rgpot-local schema diffs add, and the `&RGPOT` key table must list the keys the drop-in reads. It runs, compiles or statically checks each block according to that classification, and flags option names, paths and `RGPOT_*` names that do not exist; paths that `.gitignore` covers, such as `docs/build`, count as build outputs. `pixi r -e docs doccheck` runs it, and the docs CI job runs it with the Sphinx build, which now uses `-W --keep-going`. It replaces `docs/check_c_symbols.py`; the engines CI job no longer asks for the `c_symbols` test.

``Config::symmetry_completion_framework`` (off in every preset, and absent from the resolved configuration unless set) reads the point group of a completion from the positions alone. With species, the completion otherwise reads an operation only when it carries every point onto a point of its own species, and a structure whose positions are near a point group but whose species are placed on them in no order has no such operation. On, the group is that of the framework of positions and each species is still completed on its own sites, so the composition is kept; ``detected_symmetry::complete_detected_framework`` is the call. Without species it is the same call as ``complete_detected_classed``. It changes the walk, and the Python cluster ``Config`` reads it as ``symmetry_completion_framework``.

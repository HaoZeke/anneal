Reading a structure's point group is faster and gives the same answer. The capped symmetry scan takes the sine and cosine of each rotation order once and measures four images per pass, and the completion skips a site whose first coordinate alone is past the merge cutoff before forming the full distance. Every deviation is bit for bit the one the atom-by-atom scan gives, so no search changes. About 15% fewer instructions in the completion on a 98-point Lennard-Jones run.

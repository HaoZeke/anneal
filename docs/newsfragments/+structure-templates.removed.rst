The cluster search no longer builds structures from stored lattice templates.
The face-centred cut, the polyicosahedral cut, the Mackay cap and the axial-spine ordering are gone, and with them the labelled close-packed core cuts, the stall regrowth from a lattice order, the half-budget motif reseed and the icosahedral symmetry reseed that ran them.
The search draws every structure from its own moves and quenches, so a seeded run with the paper preset takes a different trajectory.

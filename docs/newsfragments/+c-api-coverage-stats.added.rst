``anneal_box_stats_t`` carries the remaining coverage counters of the exchange (``coverage_peer_recrossings``, ``coverage_peer_only_recrossings``, ``coverage_escape_updates``, ``coverage_novelty_updates``, ``coverage_published_samples``, ``coverage_applied_foreign_samples``, ``coverage_sample_peer_checks``, ``coverage_sample_anchor_overlaps``, ``coverage_sample_anchor_only_overlaps``, ``coverage_sample_overlaps`` and ``coverage_constrained_repulsions``), the extremes of the per-chain region counts (``coverage_regions_largest`` and ``coverage_regions_smallest``) and ``coverage_decisions``, an ``anneal_box_coverage_decisions_t``.
The fields are appended after ``coverage_repelled_proposals``, so a program built against the earlier header keeps its offsets and gets the statistics it has room for, by the ``struct_size`` it sets.
``tests/ffi_smoke.c`` checks both.

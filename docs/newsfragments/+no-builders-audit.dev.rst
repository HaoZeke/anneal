``tests/no_motif_constants.rs`` scans the search sources for size, motif and species branches and for named size constants, and fails on a hit that is not on the reviewed allowlist in ``docs/no-builders-audit.md``; an allowlist entry that no longer matches fails too. ``scripts/no_builders2/gate.py`` runs the serial paired gate for the series, interleaving a base and a new build per system and seed and appending one row per run with its revision, tree and host (``--host`` is required). ``h2h_morse`` gains the ``m38r10`` system. The plateau-heat tests run on seeds where each reset fires, so removing a reset fails its own test.

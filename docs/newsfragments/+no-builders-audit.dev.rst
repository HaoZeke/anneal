``tests/no_motif_constants.rs`` scans the search sources for size, motif and species branches and for named size constants, and fails on a hit that is not on the reviewed allowlist in ``docs/no-builders-audit.md``; an allowlist entry that no longer matches fails too. ``scripts/no_builders2/gate.py`` runs the serial paired gate for the series, interleaving a base and a new build per system and seed and appending one row per run with its revision, tree and host (``--host`` is required). ``h2h_morse`` gains the ``m38r10`` system. The plateau-heat tests run on seeds where each reset fires, so removing a reset fails its own test. ``h2h_gmin_proof`` reads ``H2H_NOSTOP=1`` to run the whole budget after a hit and ``H2H_COMPLETION=off`` or ``once`` to turn the symmetry completion off or to complete each basin once per chain, and prints the bits of the best energy and the charged count on stderr so two builds can be compared exactly.

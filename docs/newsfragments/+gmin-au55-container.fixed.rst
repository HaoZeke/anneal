The Au55 GMIN file uses a Gupta container, temperature and step. The
alloy block had left ``AVOIDRESEEDT`` true, so the first 40-step stall
scattered the 55 gold atoms and the seeds froze at their pre-reseed
best. The container follows GMIN's nearest-neighbour rule, the step
keeps taboo rejection without random reseeding, and the temperature is
0.1 eV. Appended reruns can supersede an earlier row of the same seed.
